eSMART kann unsere Zählerdaten aus der Cloud abrufen und weiterverarbeiten. eSMART entwickelt intelligente Steuerungssysteme für dein Zuhause oder Arbeitsplatz. Diese ermöglichen es, vor Ort oder von unterwegs zu überwachen, wo auf welche Weise wie viel Energie verbraucht wird. Zusätzlich stellt eSMART Werkzeuge für die Verbrauchssenkung zur Verfügung. Die smart-me Energiedaten werden direkt per API eingebunden.
