Greenpocket GmbH bringt Zählerdaten aus verschiedenen Systemen zusammen und ermöglicht personalisierte Analysen der Messdaten z.B für ISO50001 Betrachtungen.

Die smart-me Messdaten werden über [automatische MSCONS Exporte](/schnittstellen/auto-export) in die Software von Greenpocket gebracht.

Die smart-me MSCONS Daten enthalten folgende Energieträger:

- Elektrizität 

- Kaltwasser 

- Warmwasser

- Wärme

- Kälte


![GreenPocket – Abbildung 1](/img/drittsysteme-greenpocket/01.png)

Funktionen:

- Datenverwaltung von mehreren Standorten

- Alarme für aussergewöhnliche Entwicklungen an den Standorten

- Vergleichen von Datensätzen nach personalisierten Formeln
    (z.B. Elektrizität pro 100% Arbeitsstelle an Standorten)

- Standortübersichten erstellen

- Visualisierungen

- Automatisierte personalisierte Berichte

- CO2-Emissionen berechnen

- Handeintragungen von Zählerdaten ohne Integration

- Benutzerverwaltung
