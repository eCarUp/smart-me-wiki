Symcon ist eine Software, wie auch ein optionales Hardwarepaket (Symbox), das Steuerungen und Visualisierungen in Ihrem Haus oder Gebäude ermöglicht. Es fungiert als Schnittstelle und Entscheidungsträger.

Die smart-me Daten können leicht über unsere API abgefragt werden.

### Wie kriege ich einen smart-me Messpunkt in Symcon?

1.  Instanz hinzufügen (JSON Decoder)


![Symcon – Abbildung 2](/img/drittsysteme-symcon/02.png)

2\. Instanz konfigurieren

Benutzername: smart-me Account

Passwort: smart-me Passwort

URL: API Call: z.B. "https://smart-me.com:443/api/devices/&#123;id&#125;

![Symcon – Abbildung 3](/img/drittsysteme-symcon/03.png)

3\. Variable bearbeiten (Doppelklick)

![Symcon – Abbildung 4](/img/drittsysteme-symcon/04.png)

4\. Variable einstellen

- Name geben

- Ort (JSON Decoder)

- Archiveinstellungen (Aufzeichnung aktivieren und in WebFront anzeigen)


![Symcon – Abbildung 5](/img/drittsysteme-symcon/05.png)

![Symcon – Abbildung 6](/img/drittsysteme-symcon/06.png)
