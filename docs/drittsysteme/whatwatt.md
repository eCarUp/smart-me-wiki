Das whatwatt Modul ist ein kleines Hardwaremodul zur Auslesung von Energiezählern in Verwendung des Energieversorgers.
Es werden die relevanten Zählerstände, Lastprofile und Livewerte für die Leistung übertragen.

Das Modul überträgt seine Daten per API Schnittstelle direkt an unsere Cloud.



Voraussetzungen:

- Hardware Modul

- Lizenz pro Modul "Cloud2Cloud"

- Interne SD-Karte pro Modul




Anwendungen:

- Abrechnung von vZEV

- Messwertgeber zur Steuerung von Drittprodukten via Modbus TCP, MQTT oder API

- Kompatibel mit smart-me Nimbus 100A zur lokalen Auslesung per Modbus TCP


![whatwatt – Abbildung 1](/img/drittsysteme-whatwatt/01.png)

Hardwareseitige Einstellungen:

Die Übertragene Zeit muss pro Modul auf NTP Zeit gestellt werden.

1.  Öffnen Sie ihre Whatwatt APP

2.  Navigiere ins Web-UI (Browser)

3.  Klicke auf Meter

4.  Scrolle runter bis Time Handling

5.  Setze Time Handling auf "Use Networktime" in Reports
