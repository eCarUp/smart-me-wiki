## Integrationsanleitung

![Dragino LPS8N – Abbildung 1](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-dragino-lps8n/01.png)

1.  Verbinde mit dem WLAN des Dragino.
    SSID: dragino-xxxxxxx,
    Default Passwort: dragino+dragino

2.  Öffne den Browser deines Laptops und gib folgende URL in die Adressleiste ein 10.130.1.1

3.  Loge dich ein
    Default User: root
    Default Passwort: dragino

4.  Wähle "LoRaWAN" -> "LoRaWAN Semtec UDP"

5.  Wähle als Service Provider "Custom / Private LoRaWAN" ein

6.  Gib als Server Adresse: lora-gateway.smart-me.com ein

7.  Uplink und Downlink Port ist 1700

8.  Klicke auf "Save & Apply"


![Dragino LPS8N – Abbildung 2](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-dragino-lps8n/02.png)

9\. Überprüfe in der Systemübersicht dass bei Lora, IoT Service und Internet ein grüner Hacken ist.

10\. Auf [https://lora.smart-me.com](https://lora.smart-me.com)  sollte der Gateway nun als "online" angezeigt werden.
