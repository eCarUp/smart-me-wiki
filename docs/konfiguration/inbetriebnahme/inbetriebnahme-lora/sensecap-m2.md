## Integrationsanleitung

![Sensecap M2 – Abbildung 1](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-sensecap-m2/01.png)

1.  Drücke die Taste (hinten, neben dem Ethernet Anschluss) für 5s, bis die blaue LED langsam blinkt.

2.  Der Gateway hat nun ein Wlan erstellt. Verbinde mit deinem Notebook mit dem WLAN "SenseCAP\_xxxxx".
    Das Default WLAN Passwort ist 12345678

3.  Öffne den Browser deines Laptops und gib folgende URL in die Adressleiste ein 192.168.168.1 

4.  Loge dich ein:
    Default User: admin
    Das Default Passwort findest du auf der Rückseite des Gateways

5.  Wähle "LoRa" -> "LoRa Network"

6.  Wähle den Mode "Packet Forwarder"

7.  Wähle die Server Adress "lora-gateway.smart-me.com"

8.  Server Port (Up) und Server Port (Down) ist 1700

9.  Klicke auf "Save & Apply"


![Sensecap M2 – Abbildung 2](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-sensecap-m2/02.png)

10\. Überprüfe unter "Status" -> "Overview" ob zwei grüne Hacken angezeigt werden. 

11\. Auf lora.smart-me.com sollte der Gateway nun als "online" angezeigt werden.
