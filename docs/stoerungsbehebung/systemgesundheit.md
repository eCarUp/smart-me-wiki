<Menueweg>System → Systemgesundheit</Menueweg>

Die Systemgesundheit benötigt eine Professonal Lizenz 

Anzeige:

Die Geräte sind nach Typen sortiert.

- Meter Geräte: smart-me Zähler

- Pico Geräte: Pico Ladestationen

- M-Bus Gateways: Alle Gateways

- M-Bus Geräte:
    Alle vom M-Bus Gateway erzeugten Zähler.

- Andere Geräte: API oder importierte Geräte


Ordnung:

Die Spalten können sortiert werden, sind aber Default so arrangiert, damit alle Offline Geräte zuoberst erscheinen.

Device ID:

Ist die ID mit welcher dieser Zähler direkt via API angesprochen werden kann.
