<details id="wo-kann-ich-mein-login-passwort--e-mail-adresse-ändern">
<summary>Where can I change my login password / email address?</summary>

To change your login password, go to [smart-me.com](https://web.smart-me.com/login/) and log in with your existing user account. Click your user name (top right) and select Settings (Einstellungen). Click Change password (Passwort ändern).

If you no longer remember your password, you can reset it using the forgot password function (Passwort vergessen). However, this requires that a valid email address was used when the account was created.

</details>

<details id="wie-kann-ich-mein-abonnement-kündigen">
<summary>How can I cancel my subscription?</summary>

To cancel your Cloud License subscription, go to smart-me.com and log in.
Then click your user name at the top right and select Settings (Einstellungen).
Then go to Payment (Bezahlung), Cancel subscription (Abo kündigen) and confirm with Yes (Ja).

</details>

<details id="wieso-erscheint-mein-gelöschter-zähler-wieder-in-der-cloud">
<summary>Why does my deleted meter reappear in the cloud?</summary>

When a meter is deleted in the cloud, all of its data in the cloud is deleted. If this meter sends data to the cloud again after the deletion, the cloud creates the meter again (including a new meter ID). However, the meter's past measurement data is permanently deleted. If/then actions or settings in Billing also do not refer to the "new" meter and would have to be configured again accordingly. 

The following measures prevent the meter from sending data to the cloud again and thus being created again: 

- Install the meter in another account, to which it can then send its data. 

- Disconnect the meter from its power supply. However, as soon as the meter is powered again and has an internet connection, it sends its data to the cloud again. 

- Delete the WLAN from the meter (see "[Can the saved WiFi information be deleted?](/konfiguration/inbetriebnahme/smart-me-geraete#können-die-gespeicherten-wifi-informationen-gelöscht-werden)").  Without internet, the meter can no longer send data. 

Alternatively, you can also deactivate the meter in the cloud. A deactivated meter does not require any licenses, and you can reactivate it at any time and access its data. 

</details>

<details id="wie-deaktiviere-ich-meinen-zähler">
<summary>How do I deactivate my meter?</summary>

If the account uses the Basic license model.

1.  Log in to the smart-me portal 

2.   Select the meter

3.  Select the gear icon at the top right

4.  Advanced settings (Erweiterte Einstellungen) 

5.  Set Meter active (Zähler aktiv) to No (Nein)

6.  Save (Speichern)

7.  Return to the main overview or refresh the browser

If the account uses the Limited or Professional license model.

1.  Log in to the smart-me portal 

2.  Click Configure (konfigurieren)

3.  Click Meter & Folder Configuration (Zähler/Ordner-Konfiguration)

4.  Select the meter you want to deactivate

5.  Click Edit node (Knoten editieren) (on the green tile at the top)

6.  Uncheck Meter active (Zähler aktiv)

7.  Click Save (Speichern).

Alternatively, you can drag the meters into a single folder (e.g. "deactivated meters") and deactivate all meters at once by right-clicking the folder and selecting Bulk actions (Massenaktionen), Deactivate all meters (Alle Zähler deaktivieren). 

Note on deactivated meters: A deactivated meter no longer costs a license, but you also cannot access the meter's past data while it is deactivated. In addition, no new measurement data from the meter is stored in the cloud for the period during which the meter is deactivated.  

</details>
