Data protection and data security are a high priority at smart-me. We distinguish between different areas of data security:

- Devices: The communication between smart-me devices and the smart-me Cloud

- Cloud: The security of the smart-me servers

- App and web: The security of the smart-me website and the smart-me apps


You can also find further information in our comprehensive [privacy policy](https://web.smart-me.com/datenschutzerklaerung/).

## Devices

All connections between smart-me devices (meters, modules and gateways) and the smart-me Cloud are encrypted. Each device has its own unique key (256 bit). The algorithm used is the Advanced Encryption Standard (AES). This means that all communication between the smart-me Cloud and the devices is encrypted and validated. 

Tip: Actively contribute to even better protection of your data by encrypting your WiFi network with a strong password.

## Cloud

### What is the cloud?

With the cloud, data is not stored locally at the workplace but in an external, secured data center.

### Where does smart-me store the data?

smart-me attaches great importance to storing data close to the customer. The smart-me servers are located in Switzerland.  With Switzerland as the server location, we guarantee data storage in accordance with Swiss law.

The data centers are multiply certified and secured data centers. Among other things, they are certified according to ISO 27001, the recognized standard for information security.

### Fail-safety

All smart-me servers in use have at least one parallel backup system. If a server fails, the backup system automatically takes over operation without interruption. All data is stored redundantly at three different locations.

### Protection against attacks

All smart-me servers are protected against attacks behind firewalls. In addition, smart-me uses a system for detecting and preventing attacks (DDOS, WAP).

### Updates

The smart-me Cloud is continuously being improved and expanded. Updates are installed regularly and without interrupting the system.

## App and web

The [smart-me apps](https://web.smart-me.com/project/smart-me-app/) and the [smart-me website](https://web.smart-me.com/) only use secure connections via https, i.e. the connection is encrypted with SSL/TLS.
