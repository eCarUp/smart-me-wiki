Data protection and data security have a very high priority at smart-me. We distinguish between different types of data security:

- Devices: The communication of the smart-me devices with the smart-me cloud.

- Cloud: The security of the smart-me servers

- App and web: The security of the smart-me website and the smart-me apps.




You can also find more information in our detailed [privacy policy](https://web.smart-me.com/en/data-protection-declaration/).

## Devices

All connections between the smart-me devices (meters, modules and gateways) and the smart-me cloud are encrypted. Each device has its own unique key (128 bit). Advanced Encryption Standard (AES) is used as the algorithm. This means that all communication between the smart-me Cloud and the devices is encrypted and validated. Actively contribute to an even more secure protection of your data by encrypting your WiFi network with a strong password.

## Cloud

### What is the Cloud?

With the cloud, your data is no longer saved locally at your workstation, but in an external secured data centre.

### Where does smart-me save the data?

For smart-me it is very important to save the data in the vicinity of the customer: The smart-me servers are located in Switzerland. They are located in multi-certified and secured data centres; ISO 27001 certified, the recognised standard for information security. With the server location in Switzerland, we guarantee data security in accordance with Swiss law.

### Fail reliability

All smart-me servers have at least one parallel backup system. In the event of a server failure, the backup system automatically takes over operation without interruption. All data is saved redundantly in three different locations.

### Security against attacks

All smart-me servers are protected against attacks by firewalls. In addition, smart-me uses a system to detect and prevent attacks (DDOS, WAP).

### Updates

The smart-me cloud is constantly being improved and expanded. Updates are installed regularly and without interrupting the system.

## App and web

The smart-me app as well as the smart-me website only use secure connections via https, which means that the connection is encrypted with SSL/TLS.
