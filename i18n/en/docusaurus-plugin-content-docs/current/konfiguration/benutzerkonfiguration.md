In smart-me, you can create new users and grant them corresponding read-only permissions for meters or folders.

This allows you to give tenants access to their data for as long as they reside in the property.

![Creating users – figure 1](/img/_en/configuration-creating-users/01.png)

To create new users, proceed as follows:

Please note that you must first [create folders](/konfiguration/ordnerkonfiguration)

1.  Log into the [smart-me website](https://web.smart-me.com/login/)

2.  Click on Configuration in the top right-hand corner

3.  Select Configure user

4.  Create a new user by clicking Add user

5.  Use the mouse to drag the user to the folder to make it visible for this user.


![Creating users – figure 2](/img/_en/configuration-creating-users/02.png)

### Permission Level

Users always only have read-only access.

Either only the explicit node or all sub-nodes can be shared.

If a visualization that accesses meter data is used on the node, the user must be authorized to view the meter.

![Creating users – figure 3](/img/_en/configuration-creating-users/03.png)

### Next step

COnfigure now the available visualisations for tenants and owner.

### View for Tenants

A special view is available for tenants regarding virtual tariffs. It displays the current energy consumption (electricity) and its origin (solar or grid). Additionally, the bar chart illustrates the historical sources of electricity consumed.

This view must be configured separately for each apartment node.

See details on the configuration under: Visualization and Public Links

The visualization is called:  "Simple Virtual Tariffs Apartment"
