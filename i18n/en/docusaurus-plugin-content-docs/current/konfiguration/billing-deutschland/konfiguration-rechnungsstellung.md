## Residual electricity mix

<div className="row">
<div className="col col--6">

At the very top, you can define the residual electricity mix. Residual electricity is the amount of electricity that is not produced directly by your tenant electricity system but has to be supplied additionally from the grid. You receive the details of the residual electricity mix from the residual electricity supplier you have chosen.

## Consumption compared with the previous period and others

<div className="row">
<div className="col col--4">

Directly below, you can define electricity values to be used as comparison values.

The invoice document will show the electricity recipients these reference values as well as their own consumption in the previous period.

NOTE: Remember to enter the correct values  for the billing period you have chosen.  So if you create monthly invoices, choose the reference values on a monthly basis, and so on.
