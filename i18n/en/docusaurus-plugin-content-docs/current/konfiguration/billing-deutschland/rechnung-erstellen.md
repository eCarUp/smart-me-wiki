<div className="row">
<div className="col col--5">

Once the blue box for the virtual tariffs shows today's date, you can create a test invoice.

- Enter the date

- Create invoice preview (Rechnungsvorschau erstellen)

If you are satisfied with the preview, go back and create the real invoices.

Congratulations, you made it! When you now generate invoices in the smart-me Billing Tool, you receive an invoice document with all the required information and the visual charts.

This page describes the most common error messages and possible solutions: [Billing error messages](/stoerungsbehebung/billing-fehlermeldungen)
