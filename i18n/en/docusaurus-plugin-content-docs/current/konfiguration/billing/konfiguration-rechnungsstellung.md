This is where you configure billing for the properties.

## Creating a property

<div className="row">
<div className="col col--6">

The property can be added (created) in billing.

This is now done for all nodes that contain billing units.

In this step, all subfolders already created and all meters already assigned are mapped automatically. For this reason, we recommend completing these steps before you create the property in smart-me Billing.

The metering points that are to be distributed and are located in the "Technical meter" ("Technischer Zähler") node must now be assigned manually.
