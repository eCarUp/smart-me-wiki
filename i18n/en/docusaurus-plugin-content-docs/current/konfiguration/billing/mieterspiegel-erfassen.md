<div className="row">
<div className="col col--7">

For billing according to VEWA, all tenancy agreements and vacancies must be recorded with smart-me without gaps.

- Select the billing unit on the left (subfolder, e.g. WHG 1)

- Maintain the address and validity

- The e-mail address is optional and is only used for sending invoices automatically.

Note on exporting to property management software with DTA-VHKA files:
If you want to use VEWA but export the data to another system, you do not need to record a tenant list; it is created from the import file.
Make sure that all tenancies and vacancies are listed.
