## Integration guide

![Dragino LPS8N – Figure 1](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-dragino-lps8n/01.png)

1.  Connect to the Dragino's WLAN.
    SSID: dragino-xxxxxxx,
    Default password: dragino+dragino

2.  Open the browser on your laptop and enter the following URL in the address bar 10.130.1.1

3.  Log in
    Default user: root
    Default password: dragino

4.  Select "LoRaWAN" -> "LoRaWAN Semtec UDP"

5.  Select "Custom / Private LoRaWAN" as the service provider

6.  Enter as server address: lora-gateway.smart-me.com

7.  Uplink and downlink port is 1700

8.  Click on "Save & Apply"


![Dragino LPS8N – Figure 2](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-dragino-lps8n/02.png)

9\. Check in the system overview that there is a green tick next to Lora, IoT Service and Internet.

10\. On [https://lora.smart-me.com](https://lora.smart-me.com)  the gateway should now be shown as "online".
