## Integration guide

![Sensecap M2 – figure 1](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-sensecap-m2/01.png)

1.  Press the button (at the back, next to the Ethernet port) for 5s until the blue LED flashes slowly.

2.  The gateway has now created a WLAN. Connect your notebook to the WLAN "SenseCAP\_xxxxx".
    The default WLAN password is 12345678

3.  Open the browser on your laptop and enter the following URL in the address bar: 192.168.168.1 

4.  Log in:
    Default user: admin
    You will find the default password on the back of the gateway

5.  Select "LoRa" -> "LoRa Network"

6.  Select the mode "Packet Forwarder"

7.  Select the server address "lora-gateway.smart-me.com"

8.  Server Port (Up) and Server Port (Down) is 1700

9.  Click on "Save & Apply"


![Sensecap M2 – figure 2](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora-sensecap-m2/02.png)

10\. Check under "Status" -> "Overview" whether two green check marks are shown. 

11\. On lora.smart-me.com the gateway should now be shown as "online".
