## Integration guide

## Connecting the gateway to the smart-me Cloud

1.  Supply the device with power

2.  Connect your laptop to the Wifi of the WIsGate Edge (RAK7268\_XXXX), no password required.

3.  Open your web browser and go to 192.168.230.1

4.  Log in.
    Username: root
    Password: root

5.  Navigate to Overview to read out the EUI for the later connection with the Cloud.

6.  Go to Settings (Einstellungen) --> Configuration (Konfiguration)

7.  Make the following settings and save the settings.

8.  Register the device with its EUI in the smart-me LoRa Gateway
