For a virtual ZEV (vZEV), the grid operator supplies the measured values via Swisseldex (SDAT). In this case, you do not commission the meters yourself; instead, you create them in the smart-me account and connect them to the metering points supplied.

This page is currently under construction. Until then, the interface is described under [Swisseldex SDAT data import](/schnittstellen/swisseldex-sdat-import).
