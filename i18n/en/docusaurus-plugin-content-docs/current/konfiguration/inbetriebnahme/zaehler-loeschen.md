This describes how a meter can be deleted.

## General

The data of a deleted meter is irrevocably deleted and cannot be restored.

Deleting meters is generally not recommended by smart-me. We generally recommend deactivating meters. Deactivated meters do not incur any license costs and it is possible to access the historical data at any time.

Deleting M-Bus meters is not effective, as the meters will reappear in the portal the next time they are read, provided they are still online; in this case, deactivation is the only option.

## Deactivate meter

- Login to the portal

- Select meter

- Select gear wheel top right

- Advanced settings

- Set meter active to NO

- Save

- Select the arrow at the top left to return to the main overview.

- The meter is now gray.


![Delete meter – figure 1](/img/_en/configuration-commissioning-delete-meter/01.png)

## Deleting meters

- The deletion is irrevocable

- Login to the portal

- Select meter

- Select gear wheel top right

- Check whether the serial number is correct. The field must not be empty.

- Delete device

- Check whether the serial number is correct. The field must not be empty.

- Yes

- Select the arrow at the top left to return to the main overview.

- The meter is now deleted.


![Delete meter – figure 2](/img/_en/configuration-commissioning-delete-meter/02.png)
