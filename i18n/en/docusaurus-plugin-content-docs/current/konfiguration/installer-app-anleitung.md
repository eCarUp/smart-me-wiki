## Tips and tricks

### Commissioning several devices

In this step you have the option of commissioning several meters at the same time in order to speed up commissioning when there are many meters.

![Hardware Commissioning (Installer App) – Figure 33](/img/konfiguration-installer-app-anleitung/08.jpg)

### Setting the transformer ratio on the Telstar CT

1.  Select the CT meter and edit it 

2.  Enter the transformer ratio 

3.  The transformer ratio can be locked. This protects it against unwanted changes by unauthorized persons. In order for the transformer ratio to be unlocked, the device has to be installed again with the smart-me App.


### Note:

The transformer ratio does not change any historical data. This step should therefore be carried out immediately after commissioning.
