## Installation check

Installation

Check the installation quickly and easily for possible errors in the physical wiring

Load test (Lasttest)

You have lost track and no longer know which meter belongs to which apartment?

Use the hair dryer test to assign the meter to the correct apartment. Go into the apartment, plug in the hair dryer or run the kettle or the coffee machine. The meter with the largest consumption delta immediately jumps to the top of the list so you can rename it.

Connectivity (Konnektivität)

Check the connectivity of the individual devices at a glance.

Report (Protokoll)

Generate a report with serial numbers, device type and assignment for your records at the push of a button.
