## Installation check

Installation

Quickly and easily check the installation for possible errors in the physical wiring

Load test

Lost track and no longer know which meter belongs to which apartment?

Use the hair dryer test to assign the meter to the correct apartment. Go into the apartment and plug in the hair dryer, or run the kettle or the coffee machine. The meter with the largest consumption delta immediately jumps to the top of the list so you can rename it.

Connectivity

Check the connectivity of the individual devices at a glance.

Report

Create a report with serial numbers, device type and folder assignment at the push of a button.
