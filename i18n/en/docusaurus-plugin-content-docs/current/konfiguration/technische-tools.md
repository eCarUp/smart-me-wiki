## Installation check

Installation

Quickly and easily check the installation for possible errors in the physical wiring

Load test

Have you lost track and no longer know which meter belongs to which apartment?

Use the hairdryer test to assign the meter to the correct apartment. Go into the apartment, plug in the hairdryer or run the kettle or the coffee machine. The meter with the largest consumption delta immediately jumps to the top of the list so you can rename it.

Connectivity

Check the connectivity of the individual devices at a glance.

Log

Create a log with serial numbers, device type and folder assignment at the push of a button.
