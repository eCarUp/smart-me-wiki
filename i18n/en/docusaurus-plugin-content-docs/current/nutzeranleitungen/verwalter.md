## Prerequisites and checks at handover

Note: Partners are the first point of contact for property management companies if they have not attended the property manager training with us.

- Alarm (or agree on who takes care of it)

- Virtual tariffs must be set.

- Calculated date (virtual tariffs) is today.

- VEWA has been set up, if applicable.

- Tenant accesses have been set up, if agreed.

1.  Billing (Rechnungsstellung)

2.  Select Settings (Einstellungen)

3.  Define currency (CHF or EURO)

## Tenant change

How to create a tenant access, carry out a tenant change in smart-me Billing and renew tariffs.

![Guide for property managers – Figure 4](/img/nutzeranleitungen-verwalter/04.png)

### Create tenant access

Create tenant

1.  Navigate to "User configuration" ("Benutzerkonfiguration")

2.  Select "Add user" ("Benutzer hinzufügen")

3.  User name and email address
    (Tip: best practice user name = email address)

4.  Email can be fictitious or real
    (Tip: make accounts fictitious, as in the example on the right)

5.  Permission level
    (Tip: for tenants, “Read rights: Selected folders and all subfolders and meters" (“Leserechte: Ausgewühlte Ordner und alle Unterordner und Zähler") is sufficient)

6.  Validity of the access
    (Tip: Access from (Zugriff von) = move-in date / Access until (Zugriff bis) 31.12.2099)

7.  Set password

8.  Assign to the authorized node via drag and drop. (As a rule, the tenant gets access to the graphics, technical meters and their apartment)


![Guide for property managers – Figure 5](/img/nutzeranleitungen-verwalter/05.png)

### Change tenant access

When a new tenant moves in, you can prevent them from accessing the old data.

1.  Select and edit the user

2.  Set Access until (Zugriff bis) to the move-out date

3.  Alternatively, delete the tenant access


![Guide for property managers – Figure 6](/img/nutzeranleitungen-verwalter/05.png)

### The tenant change (Billing)

Billing unit

1.  Billing (Rechnungsstellung)

2.  Configuration (Konfiguration)

3.  Select billing unit

4.  Select existing tenant

5.  Edit (Editieren)

6.  Change Valid until (Gültig bis) to the move-out date.

7.  Add / edit billing address

8.  Name and address (or vacancy)

9.  Email address for
    automatic invoice sending (optional)

10.  Validity
     (Valid from (Gültig von) = move-in / Valid until (Gültig bis) = 31.12.2099)


![Guide for property managers – Figure 7](/img/nutzeranleitungen-verwalter/07.png)

### Enter electricity tariffs

Grid electricity tariffs

1.  Billing (Rechnungsstellung)

2.  Configuration (Konfiguration)

3.  Select property & select virtual tariff

4.  Edit (Editieren)

5.  Adjust price (CHF/kWh)

6.  Adjust special tax (if necessary)

7.  Save (Speichern)




Note: If anything other than the price is changed (e.g. the name or the validity), you must click “Recalculate” (“Neu rechnen”).

### Add other item

Other costs can also be added. General costs such as meter rental or administrative effort can be added at property level. 

1.  Select property

2.  Scroll all the way down to "Other" ("Sonstiges")

3.  We recommend per month (adjusts dynamically pro rata)


Apartment-specific additional costs (additional meter rental or parking fees) can be added at apartment level.

1.  Select apartment

2.  Scroll all the way down to "Other" ("Sonstiges")


Costs are not split but added equally to all.
Example: meter rental from the energy supplier 5CHF per month. 5x billing units -> 1CHF/month in other item

![Guide for property managers – Figure 12](/img/nutzeranleitungen-verwalter/12.png)

## Create invoice

### Create invoice (electricity only)

E.g. 01.10.2024 to 04.11.2024 can now be billed.

1.  Billing (Rechnungsstellung)

2.  Select Invoices (Rechnungen)

3.  Select property or billing unit

4.  Define invoice period (note: the commissioning day and the current day cannot be billed)

5.  Define invoice number (then counts up)

6.  Create invoice.

7.  Make sure there are no warnings; if there are, please check with the installation partner if the property manager training has not been attended.


![Guide for property managers – Figure 13](/img/nutzeranleitungen-verwalter/13.png)

### Create invoice (electricity and VEWA)

## Change email address (account)

Note: An account with the new email must not already exist.

1.  Click on the rocket. 

2.  Click on Account settings (Kontoeinstellungen)


![Guide for property managers – Figure 19](/img/nutzeranleitungen-verwalter/19.png)

3\. Enter current email

4\. Enter new email, confirm it and click Change email (E-Mail ändern)

5\. You will receive a confirmation link at the new email address.

Important: If this link is opened on a different device, you must log in again with the old login details.

![Guide for property managers – Figure 20](/img/nutzeranleitungen-verwalter/20.png)

## Transfer account

Note: An account with the new email must not already exist.

1.  Click on the rocket. 

2.  Click on Account settings (Kontoeinstellungen)


![Guide for property managers – Figure 21](/img/nutzeranleitungen-verwalter/19.png)

3\. Click on Transfer account (Konto übertragen)

4\. Enter and confirm the new email.

5\. Select new language.

6\. Click on Transfer account (Übertragungskonto)

7\. You will receive a link at the new email address to accept the transfer.

Important: The link is only valid for 6h. After that, the process must be started again.
