Dynamic load management on the building connection



- The maximum current at the building connection is not exceeded. 

- The charging stations statically limit the maximum outgoing feeder currents within each feeder.

- The main distribution board can still be overloaded.

- The connection at the main distribution board should therefore be sized to withstand the combined maximum currents of both feeders, or the maximum consumption of both feeders must be throttled to the main distribution board using static load management.


![E-mobility load management – Figure 2](/img/planung-e-mobility/02.png)

Dynamic load management on the main distribution board



- The maximum current at the main distribution board is not exceeded

- The charging stations statically limit the maximum outgoing feeder currents within each feeder.

- The building connection can therefore still be overloaded

- The building connection must therefore be sized large enough to withstand the combined maximum consumption of the charging stations, or the maximum power of each feeder must be throttled using static load management.
