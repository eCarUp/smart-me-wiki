The smart-me system and its hardware require a direct internet connection to the cloud. On site, you therefore need to provide a 2.4GHz WLAN with an internet connection. 5GHz is not supported due to its limited range.


Internet access can be provided as follows:

- A cable provider offering from Telekom, Vodafone, 1&1 or another local internet provider and a 2.4GHz WLAN router, usually supplied by the provider.

- Set up internet via a mobile SIM card and a 2.4GHz WLAN router. 


Redundancy levels

- Provide several access points with the same SSID and password. All smart-me products automatically select an access point with an internet connection.

- Store several WiFi networks on the smart-me device: [Can I use my device with several WiFi networks?](/konfiguration/inbetriebnahme/smart-me-geraete#kann-ich-mein-gerät-mit-mehreren-wifi-netzwerken-nutzen)

## Hardware requirements

Key points\*:

- Standard: 802.11 b / g / n 

- WiFi frequency: 2.4 GHz


\* further details can be found in the technical data of the respective [products](/produkte).

Specifications as required:

- Number of clients supported in parallel.


Clients:
The supported clients define how many devices can communicate with the access point or router in parallel. The number must suit your installation. There are cost-efficient access points that support 200+ clients.
The number can be found in the device data sheet, usually under "Max. Clients" or "Concurred Clients".

## Possible hardware components

### Router

The router is the source that is connected to the internet/provider and converts it into
LAN (RJ-45) or WiFi 2.4 Ghz / 5 GHz.

### Access points

Access points convert a signal passed on from the router via LAN (RJ-45) into a 2.4 GHz / 5GHz WLAN.

### Repeater

Repeaters amplify an existing WLAN signal to extend its range.
