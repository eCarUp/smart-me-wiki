The smart-me system and its hardware require a direct internet connection to the cloud. On site, you must therefore provide a 2.4GHz Wi-Fi network with internet access. 5GHz is not supported due to its limited range.


Internet access can be provided as follows:

- A wired provider service from Swisscom, Sunrise or another local internet provider and a 2.4GHz Wi-Fi router, usually supplied by the provider.

- Internet via a mobile SIM card and a 2.4GHz Wi-Fi router. 


Redundancy levels

- Provide multiple access points with the same SSID and password. All smart-me products automatically select an access point with an internet connection.

- Store multiple Wi-Fi networks on the smart-me device: [Can I use my device with multiple Wi-Fi networks?](/konfiguration/inbetriebnahme/smart-me-geraete#kann-ich-mein-gerät-mit-mehreren-wifi-netzwerken-nutzen)

## Hardware requirements

Key points\*:

- Standard: 802.11 b / g / n 

- Wi-Fi frequency: 2.4 GHz


\* Further details can be found in the technical data of the respective [Products](/produkte).

Specifications as required:

- Number of clients supported in parallel.


Clients:
The number of supported clients defines how many devices can communicate with the access point or router at the same time. The number must suit your installation. There are cost-efficient access points that support 200+ clients.
The number can be found in the device data sheet, usually under "Max. Clients" or "Concurred Clients".

## Possible hardware components

### Router

The router is the source that is connected to the internet/provider and converts it into
LAN (RJ-45) or Wifi 2.4 Ghz / 5 GHz.

### Access points

Access points convert a signal passed on from the router via LAN (RJ-45) into a 2.4 GHz / 5GHz Wi-Fi network.

### Repeaters

Repeaters amplify an existing Wi-Fi signal to extend its coverage.
