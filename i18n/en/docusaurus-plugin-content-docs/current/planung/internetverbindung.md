The smart-me system and its hardware require a direct internet connection to the cloud. Locally, you therefore have to provide a 2.4GHz Wi-Fi network with an internet connection. 5GHz is not supported due to its limited range.

[English](/planung/internetverbindung)

Internet access can be provided as follows:

- Provider offering via cable from Swisscom, Sunrise or another local internet provider and a 2.4GHz Wi-Fi router, usually supplied by the provider.

- Set up internet via a mobile SIM card and a 2.4GHz Wi-Fi router. 


Redundancy levels

- Provide several access points with the same SSID and password. All smart-me products automatically select an access point with an internet connection.

- Store several Wi-Fi networks on the smart-me device: [Can I use my device with several Wi-Fi networks?](/konfiguration/inbetriebnahme#where-is-the-wifi-password-saved)

## Hardware requirements

Main points\*:

- Standard: 802.11 b / g / n 

- Wi-Fi frequency: 2.4 GHz


\* further details can be found in the technical data of the respective [Products](/produkte).

Specifications as needed:

- Number of clients supported in parallel.


Clients:
The supported clients define how many devices can communicate with the access point or router in parallel. The number must match your installation. There are cost-effective access points that meet a client count of 200+.
The number can be found in the device data sheet, usually under "Max. Clients" or "Concurred Clients".

## Possible hardware components

### Router

The router is the source that is connected to the internet/provider and converts it into
LAN (RJ-45) or Wi-Fi 2.4 GHz / 5 GHz.

### Access points

Access points convert a signal passed on by the router via LAN (RJ-45) into a 2.4 GHz / 5GHz Wi-Fi network.

### Repeaters

Repeaters amplify an existing Wi-Fi signal in order to extend its range.
