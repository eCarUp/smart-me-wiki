## Certifying buildings to Minergie

To obtain certification, Minergie buildings must have energy monitoring. This can be done with the certified Minergie Monitoring module from smart-me. With the smart-me devices and gateways and the cloud interface, certification is easy to achieve.

Buildings to be certified are registered with Minergie by the project manager or Minergie specialist partner and entered on the Minergie label platform. To carry out the certification, proof of the monitoring system must be provided. 

- The planning and execution of the building certification is carried out by a Minergie specialist partner.

- The monitoring and Minergie Monitoring+, however, can be implemented by any smart-me partner with Minergie expertise.


## Easily create the Minergie Monitoring proof:

These next steps require a partnership with smart-me and a Minergie contract, or a listed smart-me system integrator acting as representative.

1.  Log in to the Minergie label platform: [https://www.label-plattform.ch/login](https://www.label-plattform.ch/login) 

2.  Navigate to "Monitoring"

3.  Select the monitoring: Standard or Light (depending on the building)

4.  Select that the proof is provided by a certified module provider

5.  Select smart-me as the module provider.


The request for proof is forwarded to smart-me, provided that no system integrator has yet been assigned to the building by the planning side.
In this case, smart-me delegates the task to one of its listed system integrators.

## Minergie Monitoring + (comparison of planned and actual data)

With its direct interface to the Minergie database, the smart-me Cloud also supports the new Minergie operation add-on modules for comparing planned data with actual data.

The data evaluation is made available on the Minergie platform and is subject to a fee charged by Minergie.

[More about Monitoring +](https://www.minergie.ch/de/zertifizieren/minergie-betrieb/)

## Becoming a smart-me partner with Minergie expertise

To implement Minergie monitoring with smart-me, you need to complete the partner training and study the Minergie regulations and guidelines yourself.

The general information can be found below.

After the self-study, an application as a system integrator can be submitted to smart-me AG. Once the application has been successfully reviewed, the system integrator is officially entered as such in the partner list. 

From then on, requests are passed on to the system integrators, and the integrators receive access to the interface for transferring data to Minergie.

## Obligations of the smart-me partner with Minergie expertise:

- Correct commissioning: The systems must be commissioned properly, and this must be documented in a commissioning report listing all devices used. The sample report provided by Minergie can be used for this purpose.


- Configuration on the label platform: Each property must be configured correctly and on time on the Minergie label platform. This includes entering the complete end customer data (name, company, address, email, phone).


- Data delivery: The system integrator is responsible for correct and complete data delivery in accordance with the "Minergie Modul Monitoring" regulations. smart-me AG of course provides technical support to help meet this requirement.


- Obligation to report changes: Minergie must be informed actively and immediately (via monitoring@minergie.ch) whenever changes are made to the monitoring system (e.g. replacement of measuring devices).


- Reporting the property to smart-me: Each property must be reported to smart-me via the designated wiki\-form. This makes it possible to forward requests to the correct partners should customers be interested later on. [Registration of the Minergie\-property](https://docs.google.com/forms/d/e/1FAIpQLScG1xwJWjP0vKgiQ1gL3gXi4rB1zEQQekRgW9bA4w_EU-4NIg/viewform?usp=header) 


- Report submission: The commissioning report for each property must be forwarded to Minergie on time or uploaded to the label platform.


### Costs related to Minergie Monitoring +

For integrators, the costs are based on Minergie's prices. The current prices can be found in the document "Reglement Minergie Monitoring" under chapter 4.4 "Royalties für Auswertung Monitoring +"

These costs are payable annually by the integrator to Minergie. 

Apart from this, Minergie charges no further costs in connection with the monitoring itself.

Note:
There are costs for certifying the building to the Minergie standard itself, but these are not charged by smart-me and are usually one-off. For more information about these costs, please contact Minergie directly via the contacts for general enquiries.

Royalties as of 11.2025 (subject to change by Minergie at any time; check the costs in the current document)
