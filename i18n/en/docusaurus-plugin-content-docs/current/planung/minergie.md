## Certify buildings to Minergie

To achieve certification, Minergie buildings must have energy monitoring. You can provide it with the certified Minergie module Monitoring from smart-me. With smart-me devices and gateways and the cloud interface, certification is straightforward.

The project manager or Minergie specialist partner registers buildings for certification with Minergie and enters them on the Minergie label platform. Before certification can be carried out, the monitoring system must be verified. 

- A Minergie specialist partner plans and carries out the building certification.

- Any smart-me partner with Minergie expertise can implement the monitoring and Minergie Monitoring+.


## Create the Minergie monitoring verification:

To carry out the following steps, you need a partnership with smart-me and a Minergie contract, or a listed smart-me system integrator acting on your behalf.

1.  Log in to the Minergie label platform: [https://www.label-plattform.ch/login](https://www.label-plattform.ch/login) 

2.  Navigate to "Monitoring"

3.  Select the monitoring type: Standard or Light (depending on the building)

4.  Select that verification is provided by a certified module provider

5.  Select smart-me as the module provider.


If the planners have not yet assigned a system integrator to the building, the verification request is forwarded to smart-me.
In that case, smart-me delegates the task to one of its listed system integrators.

## Minergie module Monitoring + (comparison of planned and actual data)

With its direct interface to the Minergie database, the smart-me Cloud also supports the new Minergie Operation add-on modules, which compare planned data with actual data.

The data analysis is provided on the Minergie platform, and Minergie charges a fee for it.

[More about Monitoring +](https://www.minergie.ch/de/zertifizieren/minergie-betrieb/)

## How to become a smart-me partner with Minergie expertise

To carry out Minergie monitoring with smart-me, you must complete the partner training and study the Minergie regulations and guidelines on your own.

General information is provided below.

After self-study, you can submit an application as a system integrator to smart-me AG. Once the application has been approved, the system integrator is officially added to the partner list. 

From then on, requests are forwarded to the system integrators, and the integrators get access to the interface for transferring data to Minergie.

## Obligations of the smart-me partner with Minergie expertise:

- Correct commissioning: The systems must be commissioned professionally, and the commissioning must be documented in a commissioning report that lists all devices used. You can use the sample report provided by Minergie for this.


- Configuration on the label platform: Each property must be configured correctly and on time on the Minergie label platform. This includes entering the complete end customer data (name, company, address, email, phone).


- Data delivery: The system integrator is responsible for correct and complete data delivery in accordance with the "Minergie Modul Monitoring" regulations. smart-me AG provides technical support to help meet this requirement.


- Duty to report changes: You must inform Minergie proactively and immediately (via monitoring@minergie.ch) whenever changes are made to the monitoring system (e.g. replacement of measuring devices).


- Registering the property with smart-me: Each property must be registered with smart-me using the dedicated Wiki\-form. This allows customer requests to be forwarded to the right partner if customers show interest later. [Registration of the Minergie\-property](https://docs.google.com/forms/d/e/1FAIpQLScG1xwJWjP0vKgiQ1gL3gXi4rB1zEQQekRgW9bA4w_EU-4NIg/viewform?usp=header) 


- Submitting the report: For each property, the commissioning report must be forwarded to Minergie or uploaded to the label platform on time.


### Costs related to Minergie Monitoring +

For integrators, the costs are based on Minergie's prices. The current prices are listed in the document "Reglement Minergie Monitoring" in chapter 4.4 "Royalties für Auswertung Monitoring +"

As an integrator, you pay these costs to Minergie annually. 

Apart from this, Minergie charges no further costs for the monitoring itself.

Note:
Certifying the building to the Minergie standard itself incurs costs. These costs are not charged by smart-me and are usually one-time. For more information about these costs, contact Minergie directly via the general enquiries contacts.

Royalties as of 11.2025 (Minergie may change them at any time; check the costs in the current document)
