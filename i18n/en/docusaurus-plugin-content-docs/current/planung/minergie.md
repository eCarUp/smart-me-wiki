## Certifying buildings to Minergie

To obtain certification, Minergie buildings must have energy monitoring. The certified Minergie module Monitoring from smart-me can provide this. The certification is easy to achieve with smart-me devices and gateways and the cloud interface.

The project manager or Minergie specialist partner registers the building with Minergie and records it on the Minergie label platform. The certification can only go ahead once the monitoring system has been verified. 

- A Minergie specialist partner plans and carries out the building certification.

- Any smart-me partner with Minergie expertise can set up the monitoring and Minergie Monitoring+.


## Creating the Minergie monitoring verification:

For the following steps, you need a partnership with smart-me and either a Minergie contract or a listed smart-me system integrator acting on your behalf.

1.  Log in to the Minergie label platform: [https://www.label-plattform.ch/login](https://www.label-plattform.ch/login) 

2.  Go to "Monitoring"

3.  Select the type of monitoring: Standard or Light (depending on the building)

4.  Select that the verification will be provided by a certified module provider

5.  Select smart-me as the module provider.


If the planners have not yet assigned a system integrator to the building, the verification request is sent to smart-me.
smart-me then passes the task on to one of its listed system integrators.

## Minergie module Monitoring + (comparison of planned and actual data)

The smart-me Cloud has a direct interface to the Minergie database, so it also supports the new Minergie Betrieb add-on modules for comparing planned data with actual data.

The data is evaluated on the Minergie platform. Minergie charges a fee for this.

[More about Monitoring +](https://www.minergie.ch/de/zertifizieren/minergie-betrieb/)

## How to become a smart-me partner with Minergie expertise

To carry out Minergie monitoring with smart-me, you must complete the partner training and study the Minergie regulations and guidelines on your own.

You will find the general information below.

After your self-study, you can apply to smart-me AG to become a system integrator. Once the application has been approved, the system integrator is officially added to the partner list. 

From then on, requests are passed on to the system integrators, and the integrators get access to the interface for sending data to Minergie.

## Obligations of a smart-me partner with Minergie expertise:

- Proper commissioning: The installations must be professionally commissioned. The commissioning must be documented in a commissioning report that lists all devices used. You can use the sample report provided by Minergie for this.


- Configuration on the label platform: Each property must be configured correctly and on time on the Minergie label platform. This includes entering the complete end-customer details (name, company, address, email, phone).


- Data delivery: The system integrator is responsible for correct and complete data delivery in accordance with the "Minergie Modul Monitoring" regulations. smart-me AG will of course provide technical support to help meet this requirement.


- Obligation to report changes: Minergie must be informed proactively and immediately (via monitoring@minergie.ch) of any changes made to the monitoring system (e.g. replacement of measuring devices).


- Notifying smart-me of the property: Each property must be reported to smart-me using the wiki\-form provided for this purpose. This makes it possible to forward requests to the right partners if customers are interested later on. [Registration of the Minergie\-property](https://docs.google.com/forms/d/e/1FAIpQLScG1xwJWjP0vKgiQ1gL3gXi4rB1zEQQekRgW9bA4w_EU-4NIg/viewform?usp=header) 


- Submitting the report: For each property, the commissioning report must be sent to Minergie or uploaded to the label platform within the deadline.


### Costs related to Minergie Monitoring +

For integrators, the costs are based on Minergie's prices. You can find the current prices in the document "Reglement Minergie Monitoring", chapter 4.4 "Royalties für Auswertung Monitoring +"

As an integrator, you pay these costs to Minergie every year. 

Minergie does not charge any other costs for the monitoring itself.

Note:
Certifying the building to the Minergie standard has its own costs. These are not charged by smart-me and are usually a one-off payment. For more information about these costs, contact Minergie directly via its general enquiries contacts.

Royalties as of 11.2025 (Minergie may change them at any time, so check the costs in the current document)
