## Minergie certification for buildings

Minergie buildings require mandatory energy monitoring in order to achieve certification. This can be done with the certified Minergie monitoring module from smart-me.

With the smart-me devices and gateways and the cloud interface, certification is easy to manage.

Buildings to be certified are registered with Minergie by the project manager or system integrator and recorded on the Minergie label platform.

The monitoring system must be verified so that certification can be carried out.

## Simply create Minergie monitoring verification:

The prerequisite for these next steps is a partnership with smart-me and a Minergie contract or a listed smart-me system integrator as a representative.

1.  Register on the Minergie Label platform: [https://www.label-plattform.ch/login](https://www.label-plattform.ch/login) 

2.  Navigate to "Monitoring"

3.  Select the monitoring: Standard or Light (depending on the building)

4.  Select that the verification is carried out with a certified module provider

5.  Select smart-me as the module provider.


The information about the request for verification is sent to smart-me if no system integrator has yet been assigned to the building by the planning department.
In this case, smart-me delegates the task to one of its listed system integrators.

## Minergie-Module Monitoring + (comparison of planned and effective data)

With its direct interface to the Minergie database, the smart-me Cloud also enables the new Minergie Operation add-on module to compare planning data and effective data.

The evaluation of the data is made available on the Minergie platform and is subject to a charge on the part of Minergie.

## Be a smart-me partner with Minergie competence

In order to implement Minergie monitoring with smart-me, you need to complete the partner training course and study the Minergie regulations and guidelines yourself.

The general information can be found below.

After self-study, an application to become a system integrator can be submitted to smart-me AG. Once the application has been successfully reviewed, the system integrator is officially entered as such in the partner list. 

From this point on, inquiries are forwarded to the system integrators and the integrators are given access to use the interface for data transfer to Minergie.

## Obligations of the partner with Minergie competence:

- Specialist knowledge and knowledge of the Minergie regulations: The system integrator ensures that he has read and understood the Minergie regulations. The system integrator assumes responsibility for the correct technical implementation of the projects and measurement concepts.

- Correct commissioning: Professional commissioning of the systems must be carried out and documented by means of a commissioning protocol that lists all the devices used. The sample protocol provided by Minergie can be used for this purpose.

- Reporting the property to smart-me: Each property must be reported to smart-me using the wiki form provided for this purpose. This makes it possible to notify the correct partners of inquiries if customers are interested at a later date. [Registration of a Minergie Property](https://docs.google.com/forms/d/e/1FAIpQLScG1xwJWjP0vKgiQ1gL3gXi4rB1zEQQekRgW9bA4w_EU-4NIg/viewform?usp=header) 

- Protocol transmission: The commissioning protocol for each property must be forwarded to Minergie or uploaded to the label platform by the deadline.

- Configuration on the label platform: Each property must be configured correctly and on time on the Minergie label platform. This includes entering the complete end customer data (name, company, address, e-mail, telephone).

- Data delivery: Correct and complete data delivery in accordance with the "Minergie Module Monitoring" regulations is the responsibility of the system integrator. Of course, smart-me AG provides technical support to ensure that this point is met.

- Obligation to report changes: Minergie must be informed actively and immediately (via [monitoring@minergie.ch](mailto:monitoring@minergie.ch) ) if changes are made to the monitoring system (e.g. replacement of measuring devices).


### Costs associated with Minergie Monitoring +

The costs for integrators are based on Minergie's prices. The current prices can be found in the document “Minergie Monitoring Regulations” under Chapter 4.4 “Royalties for Monitoring + Evaluation. These costs are payable annually by the integrator to Minergie. 

Otherwise, there are no further costs associated with the monitoring itself on the part of Minergie.

Note:
There are costs for certifying the building to the Minergie standard itself, but these costs are not charged by smart-me and are usually one-time costs. For more information on these costs, please contact the below contact "General & Platform" for general information.
