## Certifying buildings to Minergie

To obtain certification, Minergie buildings must have energy monitoring. You can use the certified Minergie Monitoring module from smart-me for this. With the smart-me devices and gateways and the cloud interface, certification is easy to achieve.

The project manager or Minergie specialist partner registers the building with Minergie and enters it on the Minergie label platform. Before the certification can be carried out, the monitoring system must be verified. 

- A Minergie specialist partner plans and carries out the building certification.

- Any smart-me partner with Minergie expertise can set up the monitoring and Minergie Monitoring+.


## Creating the Minergie monitoring verification easily:

For the following steps, you need a partnership with smart-me and a Minergie contract, or a listed smart-me system integrator acting on your behalf.

1.  Log in to the Minergie label platform: [https://www.label-plattform.ch/login](https://www.label-plattform.ch/login) 

2.  Go to "Monitoring"

3.  Select the monitoring type: Standard or Light (depending on the building)

4.  Select that the verification is provided by a certified module provider

5.  Select smart-me as the module provider.


The verification request is forwarded to smart-me if the planners have not yet assigned a system integrator to the building.
In this case, smart-me delegates the task to one of its listed system integrators.

## Minergie Monitoring + (comparison of planned and actual data)

With its direct interface to the Minergie database, the smart-me Cloud also supports the new Minergie operation add-on modules for comparing planned data with actual data.

The data analysis is provided on the Minergie platform and is charged for by Minergie.

[More about Monitoring +](https://www.minergie.ch/de/zertifizieren/minergie-betrieb/)

## How to become a smart-me partner with Minergie expertise

To implement Minergie monitoring with smart-me, you must complete the partner training and study the Minergie regulations and guidelines on your own.

You can find the general information below.

After completing the self-study, you can submit an application to smart-me AG to become a system integrator. Once the application has been successfully reviewed, the system integrator is officially added to the partner list. 

From then on, requests are passed on to the system integrators, and the integrators get access to the interface for transferring data to Minergie.

## Obligations of the smart-me partner with Minergie expertise:

- Correct commissioning: The installations must be commissioned professionally and documented in a commissioning report that lists all devices used. You can use the template report provided by Minergie for this.


- Configuration on the label platform: Each property must be configured correctly and on time on the Minergie label platform. This includes entering the complete end customer data (name, company, address, email, phone).


- Data delivery: The system integrator is responsible for correct and complete data delivery in accordance with the "Minergie Modul Monitoring" regulations. smart-me AG of course provides technical support to help meet this requirement.


- Duty to report changes: Minergie must be informed proactively and immediately (via monitoring@minergie.ch) whenever changes are made to the monitoring system (e.g. replacement of measuring devices).


- Registering the property with smart-me: Each property must be registered with smart-me using the wiki\-form provided for this purpose. This allows customer requests to be forwarded to the correct partners if customers are interested later on. [Registration of the Minergie\-property](https://docs.google.com/forms/d/e/1FAIpQLScG1xwJWjP0vKgiQ1gL3gXi4rB1zEQQekRgW9bA4w_EU-4NIg/viewform?usp=header) 


- Report submission: The commissioning report for each property must be forwarded to Minergie or uploaded to the label platform within the deadline.


### Costs related to Minergie Monitoring +

For integrators, the costs are based on Minergie's prices. You can find the current prices in the document "Reglement Minergie Monitoring" in chapter 4.4 "Royalties für Auswertung Monitoring +"

As an integrator, you pay these costs to Minergie annually. 

Apart from this, Minergie does not charge any further costs for the monitoring itself.

Note:
There are costs for certifying the building to the Minergie standard itself. However, these costs are not charged by smart-me and are usually one-off. For more information about these costs, ask the Minergie general enquiries contacts directly.

Royalties as of 11.2025 (Minergie may change them at any time; check the costs in the current document)
