The smart-me Meter is the first electricity meter that can be analyzed and controlled from anywhere. No additional hardware is required. It uses the existing WiFi network and connects directly to the smart-me Cloud. This gives you a convenient real-time view of your energy consumption.

Sales discontinued on 01.01.2023; support and cloud support remain guaranteed.

![Single Phase Meter 32A – Figure 1](/img/produkte-1-phasen-zaehler-32a/01.jpg)

## Functions

- Single-phase energy meter, 230 VAC 50/60 Hz

- Direct measurement up to 32 A

- Bidirectional meter

- Additional S0 pulse interface

- Accuracy class 1 in accordance with IEC62053-21

- Integrated data logger for two months (in the event of a connection failure)

- Direct, encrypted connection to the smart-me Cloud (WiFi)

- Comprehensive energy management in the smart-me Cloud: 

    - Real-time monitoring

    - Automatic billing ([smart-me Billing](/konfiguration/billing))

    - Control with [event-related actions](/konfiguration/wenndann-aktionen/ereignisaktionen) and [if/then actions](/konfiguration/wenndann-aktionen)

- Easy installation with the free smart-me App for [Android](https://play.google.com/store/apps/details?id=com.smart_me) and [iOS](https://apps.apple.com/ch/app/smart-me/id929146952?ign-mpt=uo%3D4)

## Technical data

Accuracy 1 in accordance with IEC62053-21

Operating voltage 85 - 253 VAC

Frequency (f) 50 / 60 Hz

Max. current 32 A (switchable)

Pulse input E1 potential-free\*, 25V - 253V AC/DC

Digital output / pulse output S0 potential-free\*, Opto Power MOSFET, 5-48VDC / 5- 230 VAC, max. 550mW

\*has no power supply of its own.

Reference current  5 A

Starting current &lt; 20 mA

Tariffs 2+

Mounting DIN rail

Width 2 modules, 36 x 90 mm

Interfaces WiFi, S0

S0 pulse rate 1000 pulses per kWh

Own consumption &lt; 0.5 W

## Configuring inputs and outputs

The smart-me Meter has one output and one input, which can be used as pulse inputs and outputs or as a switchable potential-free contact. Details can be found [here](/schnittstellen/ein_und_ausgaenge).
