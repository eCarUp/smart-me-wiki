The smart-me Plug is a power meter, thermostat and timer in one. In addition, the Plug can be controlled and monitored via web portal or app. To do this, the device connects to the internet through the local WLAN network.

Sales discontinued on 30.03.2021
Technical support discontinued on 30.03.2025
Hardware and cloud functions: operation continues to be guaranteed

![Plug – figure 1](/img/produkte-plug/01.jpg)

## Variants

Available in the Europe, Switzerland and Great Britain versions.

- UK version: 3000W (230V, 13A)

- European (Plug Type F) version: 3680W (230V, 16A)

- Swiss version: 2300W (230V, 10A)


## Functions

- Energy meter: In addition to the current power, the smart-me Plug measures energy, current, voltage and the power factor. smart-me guarantees an accuracy of 99% (max. 1% error).

- Temperature meter: Monitor the temperature live and analyse historical data.

- Remote switch: Switch the power on or off via app or web portal.

- Timer: Set the time at which the Plug should switch.

- Direct, encrypted connection to the smart-me Cloud (WiFi)

- Comprehensive energy management in the smart-me Cloud:


- -   -   Real-time monitoring

        - Control with event actions and if/then actions

    - Easy installation with the free smart-me App for Android and iOS

## Technical data

Voltage (U) 110V - 230V

Measuring range (P) 0.1-3680W

Accuracy 1 % (class 1)

Frequency (f) 50/60Hz

Current (I) 10A / 16A

Protection class IP20

Own consumption 0.1W

Dimensions 95 x 54 x 29 mm (3.7 x 2.1 x 1.1 in)

## Can the meter reading be reset.

No.
