The smart-eye brings energy meters in accordance with FNN specifications for basic meters (modern measuring devices) into the smart-me Cloud. The smart-eye is attached to the optical INFO data interface for this purpose. This transmits the energy data to the smart-me Cloud via local WiFi. Via app or online login, consumption visualisations and, if necessary, grid operation-relevant data such as frequency, voltage or current can be called up in near real time.

Sale stopped on 30.03.2021, support and cloud support is guaranteed until 30.03.2025

The smart-me system is multi-segment capable: the readings of other meters such as gas meters can also be read and integrated into the energy management. Furthermore, depending on the meter type, the smart-eye can automatically enter the pin code for the activation of the extended data set. 

![smart-eye – figure 1](/img/_en/products-smart-eye/01.jpg)

## Functions

- Real-time visualisation of the meter data

- Automatic storage of meter readings in the cloud

- Data logger: storage of readings in case of connection failure and automatic synchronisation to the cloud when the connection is restored

- Encrypted WiFi connection to the smart-me cloud

- Comprehensive energy management, automatic billing, control and alarms via the smart-me Cloud

- Easy installation with the free smart-me app for Android and IOS
