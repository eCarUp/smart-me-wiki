The smart-eye brings energy meters compliant with the FNN specification for basic meters (modern metering devices) into the smart-me Cloud. To do so, the smart-eye is attached to the optical INFO data interface. The energy data is then transmitted to the smart-me Cloud via the local WiFi. Consumption visualizations and, where applicable, grid-operation-relevant data such as frequency, voltage or current can be accessed almost in real time via the app or the online login.

Sales discontinued on 30.03.2021, support and cloud support are guaranteed until 30.03.2025.

The smart-me system supports multiple utilities: readings from other meters, such as gas meters, can also be read out and integrated into energy management. In addition, depending on the meter type, the smart-eye can automatically enter the PIN code to unlock the extended data set.

![smart-eye – Figure 1](/img/produkte-smart-eye/01.jpg)

## Functions

- Real-time visualization of the meter data

- Automatic storage of the meter readings in the cloud

- Data logger: stores the readings if the connection drops and synchronizes them automatically to the cloud once the connection is restored

- Encrypted WiFi connection to the smart-me Cloud

- Comprehensive energy management, automatic billing, control and alarms via the smart-me Cloud

- Simple installation with the free smart-me App for Android and iOS

## Technical data

Supported meters  all meters compliant with the FNN specification for basic meters

Operating voltage USB type C interface (5V)

Interfaces WiFi, INFO interface (communication with the meter)

Data storage 2 months

Firmware update possible online

Product certification CE

WiFi standard 802.11 b/g/n

WiFi security standard WEP, WPA, WPA2 (Personal)

Dimensions 34x34x25.5 mm

Weight 40 g

Temperature range −40°C to 70°C

Mounting Magnetic
