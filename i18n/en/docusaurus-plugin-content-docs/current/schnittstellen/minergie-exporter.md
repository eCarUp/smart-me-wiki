## Minergie Monitoring +

<div className="row">
<div className="col col--7">

The Minergie data exporter enables measuring point data to be transferred directly to the Minergie database.

Using the data in the Minergie database, Minergie can carry out paid comparisons of planned data and actual data.

This product is called Minergie Monitoring+ and lets you quickly and easily identify potential for improvement and uncover misconfigurations.

## Login Minergie data exporter

Every smart-me partner with the Minergie system integrator contract addendum receives the link to the exporter.

If you are not yet a Minergie system integrator, become one and find out more here: [Become a Minergie partner](/planung/minergie) 



1.  To do this, log in to [smart-me.com](http://smart-me.com) with the login details of the respective smart-me property and create the API key.

2.  Then log in to the Minergie Exporter (web address provided to you) with the same account details and create the configuration.



## Setting up the export per property

1.  Press "+" to create a new export task.


![Minergie Exporter – Figure 2](/img/schnittstellen-minergie-exporter/02.png)

2\. Create an API key in the smart-me property.

Create a new key with a name of your choice. Select at least read permissions.


![Minergie Exporter – Figure 3](/img/schnittstellen-minergie-exporter/03.png)

![Minergie Exporter – Figure 4](/img/schnittstellen-minergie-exporter/04.png)

![Minergie Exporter – Figure 5](/img/schnittstellen-minergie-exporter/05.png)

3\. Enter the key in the Minergie Exporter task under API key (API-Key)

4\. Under "Minergie target", enter the property ID that you received from Minergie and its database via the label platform.

5\. Connect the relevant measuring points from the Minergie property to a measuring point in the smart-me account. Totalizing meters can be created directly in the Minergie Exporter.

6\. Start the transfer.

![Minergie Exporter – Figure 6](/img/schnittstellen-minergie-exporter/06.png)

## Data export function and frequency

The data exporter transfers the data once a day in 15-minute intervals.

Historical data can be reloaded at any time and overwritten in the Minergie database.

When historical data is loaded, it is transferred bit by bit alongside the regular transfers. It can take a few days until all historical data has been transferred.
