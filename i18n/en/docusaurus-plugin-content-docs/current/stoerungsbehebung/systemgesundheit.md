System health requires a Professonal license

Display:

The devices are sorted by type.

- Meter devices: smart-me meters

- Pico devices: Pico charging stations

- M-Bus gateways: all gateways

- M-Bus devices:
    All meters created by the M-Bus gateway.

- Other devices: API or imported devices


Sorting:

The columns can be sorted, but by default they are arranged so that all offline devices appear at the top.

Device ID:

Is the ID with which this meter can be addressed directly via API.
