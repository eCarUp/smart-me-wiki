This page explains the known errors that can occur with virtual meters. 

Error: "Invalid formula" ("Formel ungültig")

You want to create a virtual meter and receive the following error message.

- Check whether the meter you want to add is offline.


![Virtual meter errors – Figure 1](/img/stoerungsbehebung-virtueller-zaehler-fehler/01.png)

<div className="row">
<div className="col col--7">

A meter that is offline looks like this in the folder structure.

If this is the case, go to the following page:

[Meter offline](/stoerungsbehebung/zaehler-offline)

If you no longer need the offline meter, delete it and create the virtual meter again.

The problem should then be resolved.
