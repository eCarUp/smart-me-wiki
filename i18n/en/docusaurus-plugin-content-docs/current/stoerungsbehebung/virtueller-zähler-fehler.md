This page explains the errors that are known to occur with virtual meters. 

Error: "Formula invalid" (Formel ungültig)

If you want to create a virtual meter and receive the following error message.

- Check whether the meter you want to add is offline.


![Virtual meter error – figure 1](/img/stoerungsbehebung-virtueller-zaehler-fehler/01.png)

A meter that is offline looks like this in the folder structure.

If this is the case, go to the following page:

[Meter offline](/stoerungsbehebung/zaehler-offline)

If you no longer need the meter that is offline, you have to delete it and create the virtual meter again.

The problem should then be solved.

![Virtual meter error – figure 2](/img/stoerungsbehebung-virtueller-zaehler-fehler/02.png)
