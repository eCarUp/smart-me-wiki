Greenpocket GmbH regroupe les données de compteurs issues de différents systèmes et permet des analyses personnalisées des données de mesure, par ex. pour des considérations ISO50001.

Les données de mesure smart-me sont transmises au logiciel de Greenpocket via des [exports MSCONS automatiques](/schnittstellen/auto-export).

Les données MSCONS de smart-me contiennent les agents énergétiques suivants :

- Électricité 

- Eau froide 

- Eau chaude sanitaire

- Chaleur

- Froid


![GreenPocket – Illustration 1](/img/drittsysteme-greenpocket/01.png)

Fonctions :

- Gestion des données de plusieurs sites

- Alarmes en cas d'évolutions inhabituelles sur les sites

- Comparaison de jeux de données selon des formules personnalisées
    (par ex. électricité par poste à 100 % sur les sites)

- Création de vues d'ensemble des sites

- Visualisations

- Rapports personnalisés automatisés

- Calcul des émissions de CO2

- Saisies manuelles de données de compteurs sans intégration

- Gestion des utilisateurs
