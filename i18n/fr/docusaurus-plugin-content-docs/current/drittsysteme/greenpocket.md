Greenpocket GmbH regroupe les données de compteurs issues de différents systèmes et permet des analyses personnalisées des données de mesure, p. ex. pour des études ISO50001.

Les données de mesure smart-me sont transférées dans le logiciel de Greenpocket via des [exportations MSCONS automatiques](/schnittstellen/auto-export).

Les données MSCONS de smart-me contiennent les vecteurs énergétiques suivants :

- Électricité 
- Eau froide 
- Eau chaude sanitaire
- Chaleur
- Froid

## Fonctions :

- Gestion des données de plusieurs sites
- Alarmes en cas d'évolutions inhabituelles sur les sites
- Comparaison de jeux de données selon des formules personnalisées
    (p. ex. électricité par poste à 100 % sur les sites)
- Création de vues d'ensemble des sites
- Visualisations
- Rapports personnalisés automatisés
- Calcul des émissions de CO2
- Saisie manuelle de données de compteurs sans intégration
- Gestion des utilisateurs
