smart-me est un système de gestion de l'énergie ouvert. Avec smart-me, les valeurs de mesure d'électricité, d'eau, de gaz et de chaleur peuvent être transférées dans le cloud. Pour le décompte et l'optimisation, nous proposons plusieurs outils dans notre portail. Vous pouvez toutefois aussi transférer les données énergétiques dans des systèmes tiers et utiliser leurs outils.
