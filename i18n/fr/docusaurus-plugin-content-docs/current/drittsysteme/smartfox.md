Les appareils smart-me s'intègrent directement et simplement dans une installation SMARTFOX.

![SMARTFOX – Illustration 1](/img/drittsysteme-smartfox/01.png)

Grâce au gestionnaire d'énergie intelligent SMARTFOX Pro, qui surveille et régule en continu la production et la consommation d'électricité, la consommation des appareils électriques tels que les pompes à chaleur, les bornes de recharge, etc. peut être déplacée vers les heures d'ensoleillement, ce qui augmente à la fois la part d'autoconsommation et le degré d'autarcie.

Groupe cible :

- Maison individuelle

- Petites entreprises

- Immeuble collectif


Type de connexion :

- Intégration directe via Modbus TCP pour la communication locale.


Condition :

- Licences smart-me Professional. [En savoir plus](/planung/cloud-lizenzen)


![SMARTFOX – Illustration 2](/img/drittsysteme-smartfox/02.png)

Fonctions :

- Commande

- Visualisation

- Analyse




Possibilités d'utilisation :

- Monitoring haute résolution des consommateurs

- Monitoring haute résolution des installations de production

- Fonction smartmeter au point de raccordement de l'immeuble


- Sous-compteur pour le deuxième niveau de régulation pour la gestion de la charge dynamique des bornes de recharge




## Instructions pour associer un compteur smart-me et SMARTFOX

[Instructions d'association](https://drive.google.com/file/d/1FaH_zWsVsDhH9CMsMmJ5JkJ0OZN69d2J/view?usp=drive_link) complètes avec tous les détails

### Instructions rapides

1.  [Déterminer l'adresse IP du compteur smart-me](https://sites.google.com/smart-me.com/wiki/schnittstellen/modbus-tcp#h.oomtf1ei320r).

2.  Ajouter un appareil externe dans SMARTFOX. (sélectionner smart-me Telstar)

3.  Indiquer l'adresse IP du compteur smart-me.

4.  Choisir la fonction du compteur.

5.  Enregistrer.
