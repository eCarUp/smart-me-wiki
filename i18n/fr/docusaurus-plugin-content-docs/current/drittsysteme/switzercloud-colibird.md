Le Switzercloud permet de connecter et de collecter des données à travers différents fabricants, technologies de transmission, applications et systèmes.

Avec Switzercloud, collectez les données d'appareils IoT utilisant les voies de transmission les plus diverses, des capteurs LORAWAN aux appareils Ethernet jusqu'aux transferts de données directs de cloud à cloud (API).



1.  Collecter les données

2.  Visualiser les données

3.  Traiter les données

4.  Alerter et piloter


![Switzercloud / Colibird – Illustration 1](/img/drittsysteme-switzercloud-colibird/01.png)

Le Switzercloud peut récupérer, collecter et traiter les données de mesure du portail smart-me au moyen de l'API.
Le traitement débouche sur des alertes, des rapports, des facturations, des commandes et/ou des visualisations à l'aide de Colibird.
