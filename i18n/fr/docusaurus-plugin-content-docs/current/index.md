## NOUVEAU : RCP avec systèmes d'alimentation de secours

Vous pouvez désormais tarifer les systèmes d'alimentation de secours de manière alternative.  

Comme la place manque souvent pour le compteur solaire, vous pouvez maintenant tarifer simplement à l'aide du raccordement d'immeuble et de la consommation totale, sans devoir ajouter laborieusement le compteur solaire.

Pour cela, sélectionnez le tarif solaire incl. vRCP (Solartarif inkl. vZEV) :
\- Compteur de référence : consommation et bilan (Referenzzähler: Verbrauch und Bilanz)

Les tarifs sont désormais calculés correctement sans compteur solaire, ce qui vous épargne des montages et transformations laborieux.

Remarque : si l'installation d'un compteur de production solaire est possible, n'hésitez pas à le faire. La couverture complète du schéma de mesure permet de compenser des données erronées dues à des défauts de compteur ; une omission systématique prive toutefois de cette possibilité.

## FAQ

### Où puis-je modifier mon mot de passe de connexion / mon adresse e-mail ?

Pour modifier votre mot de passe de connexion, rendez-vous sur [smart-me.com](https://web.smart-me.com/login/) et connectez-vous avec votre compte utilisateur existant. Cliquez sur votre nom d'utilisateur (en haut à droite) et sélectionnez Paramètres (Einstellungen). Cliquez sur Modifier le mot de passe (Passwort ändern).

Si vous ne vous souvenez plus de votre mot de passe, vous pouvez le réinitialiser via la fonction Mot de passe oublié (Passwort vergessen). Pour cela, une adresse e-mail valide doit toutefois avoir été utilisée lors de la création du compte.

### Comment puis-je résilier mon abonnement ?

Pour résilier votre abonnement de licences cloud, rendez-vous sur smart-me.com et connectez-vous.
Cliquez ensuite en haut à droite sur le nom d'utilisateur et sélectionnez Paramètres (Einstellungen).
Allez ensuite sur Paiement (Bezahlung), Résilier l'abonnement (Abo kündigen) et confirmez avec Oui (Ja).

### Pourquoi mon compteur supprimé réapparaît-il dans le cloud ?

Lorsqu'un compteur est supprimé dans le cloud, toutes ses données dans le cloud sont supprimées. Si ce compteur envoie à nouveau des données au cloud après la suppression, celui-ci recrée le compteur (avec un nouvel ID de compteur). Les données de mesure passées du compteur sont toutefois définitivement supprimées. Les actions si/alors ou les réglages dans le Billing ne se rapportent pas non plus au « nouveau » compteur et doivent donc être reconfigurés. 

Les mesures suivantes permettent d'éviter que le compteur envoie à nouveau des données au cloud et soit ainsi recréé : 

- Installer le compteur dans un autre compte, auquel il pourra alors envoyer les données. 

- Ne plus alimenter le compteur. Dès que le compteur est de nouveau alimenté et dispose à nouveau d'une connexion Internet, il renvoie toutefois les données au cloud. 

- Supprimer le WLAN du compteur (voir « [Les informations WiFi enregistrées peuvent-elles être supprimées ?](/konfiguration/inbetriebnahme#können-die-gespeicherten-wifi-informationen-gelöscht-werden) »).  Sans Internet, le compteur ne peut plus envoyer de données. 


Vous pouvez également désactiver le compteur dans le cloud. Un compteur désactivé ne nécessite aucune licence, et vous pouvez le réactiver à tout moment et accéder à ses données. 

### Comment désactiver mon compteur ?

Si le compte est dans le modèle de licence Basic.

1.  Connectez-vous au portail smart-me 

2.   Sélectionnez le compteur

3.  Cliquez sur la roue dentée en haut à droite

4.  Paramètres avancés (Erweiterte Einstellungen) 

5.  Réglez Compteur actif (Zähler aktiv) sur Non (Nein)

6.  Enregistrer (Speichern)

7.  Revenez à la vue d'ensemble principale ou actualisez le navigateur


Si le compte est dans le modèle de licence Limited ou Professional.

1.  Connectez-vous au portail smart-me 

2.  Cliquez sur Configurer (konfigurieren)

3.  Cliquez sur Configuration des compteurs/dossiers (Zähler/Ordner-Konfiguration)

4.  Sélectionnez le compteur à désactiver

5.  Cliquez sur Modifier le nœud (Knoten editieren) (sur la tuile verte en haut)

6.  Décochez Compteur actif (Zähler aktiv)

7.  Cliquez sur Enregistrer (Speichern).


Vous pouvez également glisser les compteurs dans un dossier (p. ex. « compteurs désactivés ») et les désactiver tous en même temps par un clic droit sur le dossier correspondant, Actions groupées (Massenaktionen), Désactiver tous les compteurs (Alle Zähler deaktivieren). 

Remarque concernant les compteurs désactivés : un compteur désactivé ne coûte plus de licence, mais vous ne pouvez plus accéder aux données passées du compteur tant qu'il est désactivé. De plus, aucune nouvelle donnée de mesure du compteur n'est enregistrée dans le cloud pendant la période où le compteur est désactivé.
