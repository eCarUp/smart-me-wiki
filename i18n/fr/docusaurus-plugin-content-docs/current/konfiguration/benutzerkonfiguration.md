### Condition préalable

Un abonnement smart-me Professional est nécessaire pour utiliser cette fonction.

Dans smart-me, tu peux créer de nouveaux utilisateurs et leur attribuer les autorisations correspondantes sur des compteurs ou des dossiers. Ces utilisateurs disposent uniquement de droits de lecture.



Cela te permet de donner aux locataires accès à leurs données tant qu'ils habitent l'immeuble.

![Créer des utilisateurs – Figure 1](/img/konfiguration-benutzerkonfiguration/01.png)

Pour créer de nouveaux utilisateurs, procède comme suit :

Veuillez noter que vous devez d'abord [créer des dossiers](/konfiguration/ordnerkonfiguration)

1.  Connecte-toi sur le [site web](https://web.smart-me.com/login/) smart-me.

2.  Clique en haut à droite sur Configuration (Konfiguration)

3.  Sélectionne Configuration des utilisateurs (Benutzerkonfiguration)

4.  Crée un nouvel utilisateur en cliquant sur Ajouter un utilisateur (Benutzer hinzufügen).

5.  Fais glisser l'utilisateur avec la souris sur le dossier qui doit être visible pour cet utilisateur.


![Créer des utilisateurs – Figure 2](/img/konfiguration-benutzerkonfiguration/02.png)

### Niveaux d'autorisation

Les utilisateurs ont toujours uniquement des accès en lecture.

Il est possible de partager soit uniquement le nœud explicite, soit celui-ci avec tous les sous-nœuds.

Si une visualisation qui accède aux données des compteurs est utilisée sur le nœud, l'utilisateur doit être autorisé à voir les compteurs.

![Créer des utilisateurs – Figure 3](/img/konfiguration-benutzerkonfiguration/03.png)

### Étape suivante

Crée maintenant les visualisations pour les locataires ou pour le propriétaire de l'immeuble.

### Vue pour les locataires

Pour les tarifs virtuels, une vue spéciale est disponible pour les locataires. Elle affiche la consommation d'énergie actuelle (électricité) et son origine (solaire ou réseau). De plus, la barre indique la source d'approvisionnement en électricité actuelle dans le passé.

Celle-ci doit être configurée en plus pour chaque nœud de logement.

Voir les détails de la configuration : [Visualisation et Public Links](/konfiguration/visualisierung) 

La visualisation s'appelle : « Einfache virtuelle Tarife Wohnung »
