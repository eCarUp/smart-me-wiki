## Paramètres généraux

<div className="row">
<div className="col col--7">

- Connectez-vous au compte smart-me souhaité 

- Cliquez en haut à droite sur « Configuration » (« Konfiguration »), puis sur « Créer une facture » (« Rechnung erstellen »)

- Sélectionnez d'abord le bouton « Paramètres » (« Einstellungen »)

C'est ici que vous définissez les paramètres généraux pour la présentation du document de facture.
- Devise (« Währung ») (toujours EUR pour l'électricité pour les locataires)
- Taxe (« Steuer ») 
- Logo de votre entreprise (pour la présentation dans le  document de facture)
- En-tête / expéditeur (« Kopfzeile / Absender »)
- Pied de page (« Fusszeile »)

</div>

## Activer l'électricité pour les locataires

<div className="row">
<div className="col col--6">

Vous pouvez en outre activer le bouton en bas, dans la section « Électricité pour les locataires Allemagne » (« Mieterstrom Deutschland »).  Les paramètres supplémentaires des extensions pour l'électricité pour les locataires sont ainsi débloqués.

</div>

### Gestionnaire de réseau de distribution (GRD)

Vous définissez ici qui est votre gestionnaire de réseau de distribution (GRD). Vous obtiendrez cette information auprès de votre installateur électricien / constructeur de l'installation photovoltaïque ou sur Internet.

### Service clientèle / organe de conciliation

**Proposition de titre :** Ce qui nous motive ? Votre satisfaction

**Proposition de texte libre (pour toute l'Allemagne / sans garantie de sécurité juridique) :**

« Le service clientèle est notre priorité absolue. Vous pouvez nous joindre au numéro 01234 / 87589.

Ces informations figurent tout en bas de votre document de facture.
