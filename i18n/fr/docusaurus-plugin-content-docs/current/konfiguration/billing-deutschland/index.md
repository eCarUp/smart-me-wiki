### Prérequis

Un abonnement smart-me Professional est nécessaire pour établir des décomptes d'électricité selon la loi allemande sur l'économie énergétique (EnWG).

Cette page vous guide dans le décompte de l'**électricité pour les locataires en Allemagne**. La variante suisse avec RCP (regroupement dans le cadre de la consommation propre) et VEWA se trouve sous [Facturation Suisse](/konfiguration/billing).

## Configurer le décompte étape par étape

Chaque étape dispose de sa propre page. Vous pouvez les parcourir dans l'ordre (le bas de chaque page indique la suite) ou passer directement d'ici à l'étape où vous vous trouvez.
