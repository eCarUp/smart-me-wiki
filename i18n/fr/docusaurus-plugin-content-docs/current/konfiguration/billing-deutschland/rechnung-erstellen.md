<div className="row">
<div className="col col--5">

Lorsque le cadre bleu des tarifs virtuels est à la date du jour, vous pouvez créer une facture d'essai.

- Saisir la date (Datum eingeben)

- Créer un aperçu de facture (Rechnungsvorschau erstellen)

Si l'aperçu vous convient, vous pouvez revenir en arrière et créer les factures réelles.

Félicitations, vous avez réussi ! Lorsque vous générez désormais des factures dans l'outil smart-me Billing, vous obtenez un document de facture contenant toutes les informations nécessaires ainsi que les représentations graphiques.

Cette page décrit les messages d'erreur les plus fréquents et les solutions possibles : [Messages d'erreur Billing](/stoerungsbehebung/billing-fehlermeldungen)
