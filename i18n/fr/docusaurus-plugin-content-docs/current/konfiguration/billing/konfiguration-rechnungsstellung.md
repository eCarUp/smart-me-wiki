## Créer un immeuble

<div className="row">
<div className="col col--6">

Dans la facturation, l'immeuble peut être ajouté (créé).

Cette opération est maintenant effectuée pour tous les nœuds qui contiennent des unités de décompte.

Lors de cette étape, tous les sous-dossiers déjà créés et les compteurs déjà attribués sont automatiquement associés. C'est pourquoi nous recommandons de les créer à chaque fois avant de créer l'immeuble dans smart-me Billing.

Les points de mesure qui doivent être répartis et qui se trouvent dans le nœud "Compteur technique" (Technischer Zähler) doivent encore être attribués manuellement.
