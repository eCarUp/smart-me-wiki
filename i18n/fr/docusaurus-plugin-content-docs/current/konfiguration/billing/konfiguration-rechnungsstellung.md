## Créer un immeuble

<div className="row">
<div className="col col--6">

Dans la facturation, il est possible d'ajouter (de créer) l'immeuble.

Cette opération est à effectuer pour tous les nœuds qui contiennent des unités de décompte.

Lors de cette étape, tous les sous-dossiers déjà créés et tous les compteurs déjà attribués sont automatiquement assignés. C'est pourquoi nous recommandons de les créer avant de créer l'immeuble dans smart-me Billing.

Les points de mesure qui doivent être répartis et qui se trouvent dans le nœud « Compteurs techniques » (Technischen Zähler) doivent encore être attribués manuellement.
