Pour le décompte selon VEWA, tous les contrats de location et toutes les vacances locatives doivent être indiqués de manière exhaustive chez smart-me.

- Menu Facturation (Rechnungsstellung)

- Configuration (Konfiguration)

- À gauche, sélectionnez l'unité de décompte (sous-dossier, p. ex. WHG 1)

- Renseignez l'adresse et la période de validité

- L'adresse e-mail est facultative et n'est utilisée que pour l'envoi automatique des factures.

Remarque concernant l'export vers des logiciels immobiliers avec des fichiers DTA-VHKA :
Si vous souhaitez utiliser la VEWA, mais exportez les données vers un autre système, vous n'avez pas besoin de saisir d'état locatif, celui-ci est créé à partir du fichier d'import.
Veillez à ce que toutes les relations locatives et toutes les vacances locatives soient répertoriées.
