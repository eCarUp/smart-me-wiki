<Menueweg>Facturation → Immeubles & tarifs → Unité d'habitation / commerciale (Wohn-/ Gewerbeeinheit)</Menueweg>

<div className="row">
<div className="col col--7">

Pour le décompte selon VEWA, tous les contrats de location et toutes les vacances doivent être indiqués sans lacune chez smart-me.

- Sélectionner l'unité de décompte à gauche (sous-dossier, p. ex. WHG 1)

- Saisir l'adresse et la période de validité

- L'adresse e-mail est facultative et n'est utilisée que pour l'envoi automatique des factures.

Remarque pour l'exportation vers des logiciels immobiliers avec des fichiers DTA-VHKA :
Si vous souhaitez utiliser la VEWA, mais exportez les données vers un autre système, vous n'avez pas besoin de saisir d'état locatif ; celui-ci est créé à partir du fichier d'importation.
Veillez à ce que tous les rapports de location et toutes les vacances soient enregistrés.
