## Introduction

Dans smart-me Billing, quelques réglages supplémentaires permettent d'établir des factures d'électricité conformes aux prescriptions du paragraphe § 42 de la loi allemande sur l'économie énergétique (EnWG).

IMPORTANT : pour pouvoir effectuer correctement les réglages supplémentaires pour l'électricité pour les locataires, vous devez avoir configuré au préalable les [tarifs virtuels](/konfiguration/billing) de votre immeuble et effectué les réglages normaux de [smart-me Billing](/konfiguration/billing).

IMPORTANT : pour l'électricité pour les locataires, il faut toujours travailler avec les [tarifs virtuels](/konfiguration/billing).

## Réglages généraux

- Connectez-vous au compte smart-me souhaité

- Cliquez en haut à droite sur "Configuration" (Konfiguration), puis sur "Créer une facture" (Rechnung erstellen)

- Choisissez d'abord le bouton "Paramètres" (Einstellungen)


Vous y effectuez les réglages généraux pour la présentation du document de facture. Vous y effectuez également les réglages déjà décrits dans l'[article Billing](/konfiguration/billing) normal :


- Devise (toujours EUR pour l'électricité pour les locataires)

- Taxe

- Logo de votre entreprise (pour la présentation dans le document de facture)

- En-tête / expéditeur

- Pied de page


![smart-me Billing pour l'électricité pour les locataires en Allemagne – figure 3](/img/konfiguration-billing-mieterstrom/03.png)

Vous pouvez en outre activer le bouton en bas, dans la zone "Électricité pour les locataires Allemagne" (Mieterstrom Deutschland). Les réglages supplémentaires pour les extensions d'électricité pour les locataires sont ainsi débloqués.

Vous pouvez effectuer directement ici les extensions suivantes :

## Configuration de l'immeuble

Passez à l'onglet "Configuration" (Konfiguration) en haut. Vous pouvez y effectuer les extensions débloquées pour l'immeuble et pour les différents logements. Cliquez d'abord sur le dossier de l'immeuble souhaité.

![smart-me Billing pour l'électricité pour les locataires en Allemagne – figure 5](/img/konfiguration-billing-mieterstrom/05.png)

### Composition de l'électricité complémentaire

Tout en haut, vous pouvez définir la composition de l'électricité complémentaire. L'électricité complémentaire est la quantité d'électricité qui n'est pas produite directement par votre installation d'électricité pour les locataires, mais qui doit être fournie en plus par le réseau. Vous obtenez les indications sur la composition de l'électricité complémentaire auprès du fournisseur d'électricité complémentaire que vous avez choisi.

Un exemple peut se présenter ainsi :

![smart-me Billing pour l'électricité pour les locataires en Allemagne – figure 6](/img/konfiguration-billing-mieterstrom/06.png)

### Consommation par rapport à la période précédente et à d'autres

Juste en dessous, vous pouvez définir des valeurs de comparaison pour la consommation d'électricité.

Le document de facture indiquera aux bénéficiaires de l'électricité ces valeurs de référence ainsi que leur propre consommation de la période précédente.

ATTENTION : pensez à saisir les bonnes valeurs pour la période de décompte que vous avez choisie. Si vous établissez des factures mensuelles, choisissez donc des valeurs de référence sur une base mensuelle, etc.

Conseil pratique : directement sous le champ de saisie pour la consommation par rapport à la période précédente et à d'autres, vous trouvez les [tarifs virtuels](/konfiguration/billing) que vous avez déjà configurés. Si vous souhaitez facturer un tarif unique (l'électricité du réseau et l'électricité solaire ont le même prix), vous devez tout de même définir deux tarifs (au même prix) dans un modèle d'électricité pour les locataires. Cela garantit que notre outil Billing peut déterminer correctement les taxes relatives aux différentes composantes de l'électricité.

### Définition des composantes tarifaires par type d'électricité

Plus bas, sous "Divers" (Sonstiges), vous pouvez définir les composantes tarifaires par type d'électricité (réseau et solaire). Le but est de montrer au client final comment se compose son prix de l'électricité. Vous devez le faire aussi bien pour l'électricité du réseau que pour l'électricité solaire. Ensemble, les composantes doivent correspondre au prix que vous avez défini par type d'électricité (fixé dans les [tarifs virtuels](/konfiguration/billing)), sinon Billing affiche un message d'erreur.

![smart-me Billing pour l'électricité pour les locataires en Allemagne – figure 8](/img/konfiguration-billing-mieterstrom/08.png)

Vous pouvez soit insérer directement les composantes tarifaires standard pour l'électricité pour les locataires, soit saisir des composantes tarifaires individuelles via "Modifier" (Editieren).

Important : choisissez le type correct lors de la modification, c'est-à-dire précisez s'il s'agit d'une composante tarifaire de l'électricité du réseau (électricité complémentaire) ou de l'électricité solaire.


Important : vous obtenez les indications sur la composition des composantes de l'électricité du réseau (électricité complémentaire) auprès du fournisseur d'électricité complémentaire que vous avez choisi.

L'électricité solaire se compose généralement uniquement de la contribution EEG et du prix de production.

![smart-me Billing pour l'électricité pour les locataires en Allemagne – figure 9](/img/konfiguration-billing-mieterstrom/09.png)

Une configuration terminée peut se présenter ainsi :

## Configuration des logements

Cliquez maintenant successivement sur les différents logements de votre immeuble et spécifiez-les.

### Numéro de client

Vous définissez ici le numéro de client de ce locataire.

Remarque :

Le numéro de client est automatiquement utilisé aussi comme nom du document PDF, pour faciliter l'identification externe.

### Contrat et durée

Vous pouvez insérer ici des dispositions contractuelles. Un exemple (sans garantie de sécurité juridique) serait :

Votre contrat court jusqu'au DD.MM.YYYY et est prolongé d'un an conformément à la réglementation du chiffre X de votre contrat de fourniture d'électricité, à défaut de résiliation en temps utile. Vous pouvez résilier le contrat de fourniture d'électricité moyennant un préavis de trois mois pour le DD.MM.YYYY, conformément au chiffre X du contrat de fourniture d'électricité. Un droit de résiliation extraordinaire demeure réservé
