## 1\. Enregistrer la passerelle LoRa sur smart-me

<div className="row">
<div className="col col--6">

1.  Rendez-vous sur [lora.smart-me.com](https://lora.smart-me.com) et connectez-vous avec votre compte smart-me. 

2.  Sélectionnez "Passerelles Lora" (Lora Gateways) et cliquez sur "Ajouter" (Hinzufügen)

3.  Saisissez le nom ainsi que l'EUI de l'appareil. Vous pouvez aussi scanner le code QR de l'EUI avec l'appareil photo.

</div>
<div className="col col--6 text--center">

![Mise en service LoRa – illustration 1](/img/konfiguration-inbetriebnahme-inbetriebnahme-lora/01.png)

</div>
</div>

## 3\. Ajouter les compteurs et les capteurs

<div className="row">
<div className="col col--5">

1.  Allez dans l'onglet "Appareils Lora" (Lora Geräte)

2.  Sélectionnez "Ajouter" (Hinzufügen)

3.  Saisissez les informations demandées sur le compteur ou le capteur.

4.  Cliquez sur "Enregistrer" (Speichern)

5.  Vérifiez l'état du capteur dans l'aperçu des appareils Lora (Lora Geräte Übersicht).

</div>
