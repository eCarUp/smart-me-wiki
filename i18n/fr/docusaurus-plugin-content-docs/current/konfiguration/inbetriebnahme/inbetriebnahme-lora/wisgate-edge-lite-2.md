## Guide d'intégration

## Connexion de la passerelle au cloud smart-me

1.  Mets l'appareil sous tension

2.  Connecte ton ordinateur portable au réseau Wifi du WIsGate Edge (RAK7268\_XXXX), aucun mot de passe n'est nécessaire.

3.  Ouvre ton navigateur web et accède à 192.168.230.1

4.  Connecte-toi.
    Username: root
    Passwort: root

5.  Va dans Overview pour relever l'EUI, nécessaire pour la connexion ultérieure au cloud.

6.  Accède aux paramètres (Einstellungen) --> configuration (Konfiguration)

7.  Effectue les réglages suivants et enregistre les réglages.

8.  Enregistre l'appareil avec son EUI dans le LoRa Gateway smart-me
