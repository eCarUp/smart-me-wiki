## Instructions d'intégration

## Connexion de la passerelle au cloud smart-me

<div className="row">
<div className="col col--7">

1.  Mettez l'appareil sous tension.

2.  Connectez votre ordinateur portable au Wifi du WIsGate Edge (RAK7268\_XXXX). Aucun mot de passe n'est nécessaire.

3.  Ouvrez votre navigateur web et accédez à 192.168.230.1

4.  Connectez-vous.

    Username: root

    Mot de passe: root

5.  Allez dans Overview pour relever l'EUI, dont vous aurez besoin plus tard pour la connexion au cloud.

6.  Ouvrez Paramètres --> Configuration (Einstellungen --> Konfiguration).

7.  Effectuez les réglages suivants et enregistrez-les.

8.  Enregistrez l'appareil avec son EUI dans la Passerelle LoRa (LoRa Gateway) de smart-me.
