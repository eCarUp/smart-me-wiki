## Guide d'intégration

## Connexion de la passerelle au cloud smart-me

<div className="row">
<div className="col col--7">

1.  Mettez l'appareil sous tension.

2.  Avec votre ordinateur portable, connectez-vous au réseau Wifi du WIsGate Edge (RAK7268\_XXXX). Aucun mot de passe n'est nécessaire.

3.  Ouvrez votre navigateur web et accédez à 192.168.230.1

4.  Connectez-vous.

    Username: root

    Passwort: root

5.  Naviguez jusqu'à Overview pour relever l'EUI, nécessaire plus tard pour la connexion au cloud.

6.  Allez dans Paramètres --> Configuration (Einstellungen --> Konfiguration)

7.  Effectuez les réglages suivants et enregistrez-les.

8.  Enregistrez l'appareil avec son EUI dans la Passerelle LoRa (LoRa Gateway) de smart-me.
