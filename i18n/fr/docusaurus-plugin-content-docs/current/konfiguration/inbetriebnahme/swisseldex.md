Dans le cas d'un RCP virtuel (vRCP), le gestionnaire de réseau de distribution (GRD) fournit les valeurs de mesure via Swisseldex (SDAT). Les compteurs ne sont alors pas mis en service par vos soins, mais créés dans le compte smart-me et reliés aux points de mesure fournis.

Cette page est en cours de rédaction. D'ici là, la description de l'interface se trouve sous [Importation vRCP-Swisseldex (SDAT)](/schnittstellen/swisseldex-sdat-import).
