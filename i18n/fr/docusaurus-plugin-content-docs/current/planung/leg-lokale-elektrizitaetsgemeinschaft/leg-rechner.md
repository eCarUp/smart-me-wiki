L'aide à la décision demande successivement la taille de l'installation, l'injection,
les participants, le prix CEL et les coûts, puis montre à la fin comment une CEL se compare
à la rétribution actuelle de l'injection. Les données saisies ne sont pas transmises :
**Enregistrer le projet (Projekt speichern)** les enregistre sous forme de fichier JSON sur votre propre ordinateur,
**Ouvrir le projet (Projekt öffnen)** les recharge depuis cet emplacement.
