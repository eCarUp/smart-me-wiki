## Tarification du schéma de mesure standard

La tarification du schéma de mesure s'effectue via le compteur de bilan et la production ou, en alternative, via consommation / PV ou batterie avec référencement du compteur de bilan.

### Tarification avec le tarif solaire RCP virtuel (vRCP) inclus

Le compteur de bilan est référencé pour le calcul de la tarification.

Si vous utilisez le tarif solaire vRCP inclus (Solartarif inkl. vZEV), aucune licence supplémentaire pour les compteurs virtuels n'est facturée.

Compteur de bilan (Bilanzzähler)

Le compteur du raccordement d'immeuble est référencé comme compteur de bilan.

![Schéma de mesure standard – illustration 2](/img/planung-standard-messkonzept/02.png)

Compteur de production

Tous les compteurs de production et compteurs de batterie sont saisis sous Production (Produktion).

![Schéma de mesure standard – illustration 3](/img/planung-standard-messkonzept/03.png)

### Tarification au moyen du tarif solaire (consommation / PV) avec ou sans tarif batterie (consommation / batterie)

Le compteur de bilan est ignoré pour le calcul de la tarification ; il n'est pris en compte que plus tard, à des fins de vérification.

Si vous utilisez le tarif solaire (consommation / PV), des licences supplémentaires pour les compteurs virtuels sont facturées.

La consommation totale est requise au minimum. Elle est créée sous forme de compteur virtuel composé de tous les départs participant à l'électricité pour les locataires.

Consommation totale = Appartement 1.1 + Appartement 1.2 + Appartement 2.1 + Parties communes + Place de parc 1 + Place de parc 2 + Pompe à chaleur

Sous Production (Produktion), ajoutez à chaque fois le compteur de l'installation solaire ou, pour le tarif batterie, le compteur de batterie.

Sous Consommation totale (Gesamtverbrauch), indiquez la consommation totale créée virtuellement.

Le compteur de bilan est ici volontairement référencé afin d'augmenter la précision !

![Schéma de mesure standard – illustration 4](/img/planung-standard-messkonzept/04.png)

### Validation et décompte du fournisseur d'électricité

Les sommes de l'électricité du réseau vendue correspondent approximativement à la quantité d'électricité facturée par le fournisseur d'électricité

La quantité d'électricité réinjectée dans le registre d'export du compteur de bilan correspond approximativement à la quantité figurant dans la rétribution de l'injection du fournisseur d'électricité.
