## Tarification du schéma de mesure standard

La tarification du schéma de mesure s'effectue via le compteur de bilan et la production, ou alternativement via la consommation / le PV ou la batterie, avec référencement du compteur de bilan.

### Tarification avec tarif solaire, vRCP inclus

Le compteur de bilan est référencé pour le calcul de la tarification.

Si vous utilisez le tarif solaire avec vRCP inclus, aucune licence supplémentaire n'est due pour les compteurs virtuels.

Compteur de bilan

Le compteur du raccordement de l'immeuble est référencé comme compteur de bilan (Bilanzzähler).

![Schéma de mesure standard – illustration 2](/img/planung-standard-messkonzept/02.png)

Compteur de production

Tous les compteurs de production et compteurs de batterie sont saisis comme production (Produktion).

![Schéma de mesure standard – illustration 3](/img/planung-standard-messkonzept/03.png)

### Tarification au moyen du tarif solaire (consommation / PV), avec ou sans tarif batterie (consommation / batterie)

Le compteur de bilan est ignoré pour le calcul de la tarification ; il n'est consulté ultérieurement qu'à des fins de vérification.

Si vous utilisez le tarif solaire (consommation / PV), des licences supplémentaires sont dues pour les compteurs virtuels.

La consommation totale est requise au minimum. Elle est créée comme compteur virtuel, composé de tous les départs participant à l'électricité pour les locataires.

Consommation totale = Appartement 1.1 + Appartement 1.2 + Appartement 2.1 + Parties communes + Place de parc 1 + Place de parc 2 + Pompe à chaleur

Sous Production (Produktion), ajoutez à chaque fois le compteur de l'installation solaire ou, pour le tarif batterie, le compteur de batterie.

Sous Consommation totale (Gesamtverbrauch), enregistrez la consommation totale créée virtuellement.

Le compteur de bilan est ici délibérément référencé afin d'augmenter la précision !

![Schéma de mesure standard – illustration 4](/img/planung-standard-messkonzept/04.png)

### Validation et décompte du fournisseur d'électricité

Les sommes de l'électricité du réseau vendue correspondent approximativement à la quantité d'électricité facturée par le fournisseur d'électricité

La quantité d'électricité réinjectée dans le registre d'export du compteur de bilan correspond approximativement à la quantité indiquée dans la rétribution de l'injection du fournisseur d'électricité.
