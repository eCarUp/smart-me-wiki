Le compteur monophasé 80A de smart-me est un compteur d'énergie doté d'une interface WiFi intégrée pour la transmission de données en temps réel. Le compteur synchronise automatiquement les valeurs mesurées, de manière chiffrée, vers le cloud smart-me. Les données peuvent être exportées et traitées dans le portail smart-me ou, via notre interface ouverte, dans des systèmes tiers. Le compteur dispose d'une sortie numérique pour la commande d'appareils libres de potentiel.

## Écran

Le compteur affiche alternativement différentes valeurs.

- « So XXXX » est la version du logiciel installée.

- « CH XXXX » est la somme de contrôle du logiciel.

- « Nombre + T1/T2 » est la valeur du tarif correspondant.

- « Er XX » est un code d'erreur.

## Fonctions des touches

Touche T(4) pour l'installation

Si la touche T(4) est maintenue enfoncée pendant 10 secondes, un réseau WiFi local est créé pour l'installation.

## Configurer les entrées et sorties

Le compteur monophasé 80A dispose d'une sortie numérique et d'une entrée numérique, qui peuvent être utilisées comme entrées et sorties d'impulsions ou comme contact commutable libre de potentiel. Vous trouverez plus de détails sur la page wiki [Entrées et sorties](/schnittstellen/ein-und-ausgaenge)

## FAQ

<details id="in-welchem-intervall-senden-die-zähler-daten">
<summary>À quel intervalle les compteurs envoient-ils des données ?</summary>

- Avec les licences Basic ou Limited : max. 1x par minute.

- Avec une licence Pro : max. 1x par seconde

</details>

<details id="kann-ich-den-zählerstand-auf-null-zurücksetzten">
<summary>Puis-je remettre le relevé du compteur à zéro ?</summary>

Non, nos compteurs étant utilisés pour des décomptes, il n'est pas possible de les remettre à zéro.

</details>
