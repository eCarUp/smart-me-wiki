Le compteur monophasé 80A smart-me est un compteur d'énergie doté d'une interface WiFi intégrée pour la transmission de données en temps réel. Le compteur synchronise les valeurs mesurées de manière automatisée et chiffrée dans le smart-me Cloud. Les données peuvent être exportées et traitées dans le portail smart-me ou, via notre interface ouverte, dans des systèmes tiers. Le compteur dispose d'une sortie numérique permettant de commander des appareils libres de potentiel.

## Écran

Le compteur affiche alternativement différentes valeurs.

- "So XXXX" correspond à la version du logiciel installée.

- "CH XXXX" correspond à la somme de contrôle du logiciel.

- "Nombre + T1/T2" correspond à la valeur du tarif concerné

- "Er XX" est un code d'erreur.

## Fonctions des touches

Touche T(4) pour l'installation

Si vous appuyez sur la touche T(4) pendant 10 secondes, un réseau WiFi local est créé pour l'installation

## Configurer les entrées et sorties

Le compteur monophasé 80A dispose d'une sortie numérique et d'une entrée numérique, qui peuvent être utilisées comme entrée et sortie d'impulsions ou comme contact commutable libre de potentiel. Vous trouverez plus de détails à ce sujet sur la page du wiki [Entrées et sorties](/schnittstellen/ein_und_ausgaenge)

## FAQ

### À quel intervalle les compteurs envoient-ils des données?

- Avec les licences Basic ou Limited: max. 1x par minute.

- Avec la licence Pro: max. 1x par seconde


### Puis-je remettre le relevé du compteur à zéro?

Non, nos compteurs étant utilisés pour des décomptes, il n'est pas possible de les remettre à zéro.
