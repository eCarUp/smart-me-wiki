Le compteur monophasé smart-me 80A est un compteur d'énergie doté d'une interface WiFi intégrée pour la transmission de données en temps réel. Le compteur synchronise les valeurs de mesure de manière automatisée et chiffrée vers le cloud smart-me. Les données peuvent être consultées dans le portail smart-me ou exportées et traitées dans des systèmes tiers via notre interface ouverte. Le compteur dispose d'une sortie numérique permettant de commander des appareils libres de potentiel.

## Écran

Le compteur affiche différentes valeurs en alternance.

- « So XXXX » est la version du logiciel installée.

- « CH XXXX » est la somme de contrôle du logiciel.

- « Nombre + T1/T2 » est la valeur du tarif correspondant

- « Er XX » est un code d'erreur.

## Fonctions des touches

Touche T(4) pour l'installation

Si la touche T(4) est maintenue enfoncée pendant 10 secondes, un réseau WiFi local est créé pour l'installation

## Configurer les entrées et sorties

Le compteur monophasé 80A dispose d'une sortie numérique et d'une entrée numérique, qui peuvent être utilisées comme entrées et sorties d'impulsions ou comme contact commutable libre de potentiel. Vous trouverez les détails à ce sujet sur la page wiki [Entrées et sorties](/schnittstellen/ein_und_ausgaenge)

## FAQ

### À quel intervalle les compteurs envoient-ils des données ?

- Avec les licences Basic ou Limited : max. 1× par minute.

- Avec la licence Pro : max. 1× par seconde


### Puis-je remettre le relevé du compteur à zéro ?

Non, comme nos compteurs sont utilisés pour des décomptes, il n'est pas possible de les remettre à zéro.
