Le compteur monophasé smart-me 80A est un compteur d'énergie avec interface WiFi intégrée pour la transmission de données en temps réel. Le compteur synchronise les valeurs de mesure de manière automatisée et chiffrée vers le cloud smart-me. Les données peuvent être exportées et retraitées dans le portail smart-me ou vers des systèmes tiers via notre interface ouverte. Le compteur dispose d'une sortie numérique pour la commande d'appareils libres de potentiel.

![Compteur monophasé 80A – Illustration 1](/img/produkte-1-phasen-zaehler/01.jpg)

## Fonctions

- [Installation](/konfiguration/inbetriebnahme) avec l'application smart-me gratuite.

- Commande avec des [actions si/alors](/konfiguration/wenndann-aktionen) ou des [actions déclenchées par un événement](/konfiguration/wenndann-aktionen/ereignisaktionen)

- [Visualisations](/konfiguration/visualisierung)

- [Sortie de contact libre de potentiel](/schnittstellen/ein_und_ausgaenge) pour la commande d'appareils externes

- Entrée de contact libre de potentiel pour signal tarifaire ou [entrée numérique](/schnittstellen/ein_und_ausgaenge)

- [Interfaces](/) via API, CSV, MSCONS et IS-E

- Connexion de données chiffrée en temps réel vers le cloud smart-me

## Écran

Le compteur affiche différentes valeurs en alternance.

- « So XXXX » est la version logicielle installée.

- « CH XXXX » est la somme de contrôle du logiciel.

- « Nombre + T1/T2 » est la valeur du tarif correspondant

- « Er XX » est un code d'erreur.

## Fonctions des touches

Touche T(4) pour l'installation

Si la touche T(4) est maintenue enfoncée pendant 10 secondes, cela crée un WiFi local pour l'installation

## Configurer les entrées et sorties

Le compteur monophasé 80A dispose d'une sortie numérique et d'une entrée numérique, qui peuvent être utilisées comme entrées et sorties d'impulsions ou comme contact libre de potentiel commutable. Tu trouveras les détails à ce sujet sur la page wiki [Entrées et sorties](/schnittstellen/ein_und_ausgaenge)

## FAQ

### À quel intervalle les compteurs envoient-ils des données ?

- Avec les licences Basic ou Limited : max. 1x par minute.

- Avec la licence Pro : max. 1x par seconde


### Puis-je remettre le relevé du compteur à zéro ?

Non, comme nos compteurs sont utilisés pour des décomptes, il n'est pas possible de les réinitialiser.
