## 212070/VP Pack de préparation Pico

Le pack de préparation Pico permet de préinstaller d'éventuelles bornes de recharge supplémentaires. La livraison comprend la plaque de base et un cache d'obturation.

Dès qu'une extension devient nécessaire, l'électronique Pico peut être commandée séparément, sans plaque de montage, sous le numéro d'article 212070/1.
Le montage se fait en encliquetant l'électronique Pico dans la plaque de montage, puis en la vissant à celle-ci.
