Le smart-eye intègre les compteurs d'énergie conformes au cahier des charges FNN pour compteurs de base (dispositifs de mesure modernes) dans le cloud smart-me. Pour cela, le smart-eye se fixe sur l'interface de données optique INFO. Les données énergétiques sont ainsi transmises au cloud smart-me via le WiFi local. Via l'app ou la connexion en ligne, les visualisations de consommation ainsi que, le cas échéant, les données pertinentes pour l'exploitation du réseau telles que la fréquence, la tension ou le courant sont consultables quasiment en temps réel.

Vente arrêtée le 30.03.2021, le support et la prise en charge par le cloud sont garantis jusqu'au 30.03.2025.

Le système smart-me est multifluide : les valeurs de mesure d'autres compteurs, comme par exemple les compteurs de gaz, peuvent également être relevées et intégrées à la gestion de l'énergie. En outre, selon le type de compteur, le smart-eye peut saisir automatiquement le code PIN permettant de déverrouiller le jeu de données étendu.

![smart-eye – Illustration 1](/img/produkte-smart-eye/01.jpg)

## Fonctions

- Visualisation en temps réel des données du compteur

- Enregistrement automatique des relevés du compteur dans le cloud

- Enregistreur de données : mémorisation des valeurs de mesure en cas de coupure de la connexion et synchronisation automatique vers le cloud dès le rétablissement de la connexion

- Connexion WiFi chiffrée au cloud smart-me

- Gestion complète de l'énergie, facturation automatique, commande et alarmes via le cloud smart-me

- Installation simple avec l'app smart-me gratuite pour Android et iOS

## Caractéristiques techniques

Compteurs pris en charge  tous les compteurs selon le cahier des charges FNN pour compteurs de base

Tension d'alimentation interface USB type C (5V)

Interfaces WiFi, interface INFO (communication avec le compteur)

Mémoire de données 2 mois

Mise à jour du firmware possible en ligne

Certification du produit CE

Standard WiFi 802.11 b/g/n

Standard de sécurité WiFi WEP, WPA, WPA2 (Personal)

Dimensions 34x34x25.5 mm

Poids 40 g

Plage de température −40°C à 70°C

Montage magnétique
