Il vous faut un abonnement eCarUp Premium par station pour facturer les données importées ou les transférer vers d'autres systèmes.

Vous trouverez un aperçu détaillé sur la page du wiki eCarUp [Import de données 15 minutes](https://ecarupwiki.smart-me.com/funktionen/15-minuten-datenimport).
