## Interface P1

L'interface P1 permet de transmettre les données en direct de notre matériel de comptage vers des systèmes tiers. Les données peuvent ensuite être utilisées pour l'analyse ou la commande.

Pour pouvoir utiliser cette interface, un module de lecture P1 prenant en charge le standard du protocole est nécessaire.
Vous trouverez les informations sur le standard concerné dans les téléchargements spécifiques au produit.
