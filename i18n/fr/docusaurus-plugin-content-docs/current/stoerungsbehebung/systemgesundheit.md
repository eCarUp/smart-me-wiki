L'état du système (Systemgesundheit) nécessite une licence Professonal 

Affichage :

Les appareils sont triés par type.

- Appareils Meter : compteurs smart-me

- Appareils Pico : bornes de recharge Pico

- M-Bus Gateways : tous les gateways

- Appareils M-Bus :
    tous les compteurs créés par le M-Bus Gateway.

- Autres appareils : appareils API ou importés


Tri :

Les colonnes peuvent être triées, mais elles sont arrangées par défaut de manière à ce que tous les appareils hors ligne apparaissent en haut.

Device ID :

Il s'agit de l'ID avec lequel ce compteur peut être adressé directement via l'API.
