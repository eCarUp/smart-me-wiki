Cette page décrit les erreurs connues concernant les compteurs virtuels. 

Erreur : « Formule invalide » (Formel ungültig)

Lorsque vous souhaitez créer un compteur virtuel et que vous obtenez le message d'erreur suivant.

- Vérifiez si le compteur que vous souhaitez ajouter est hors ligne.


![Erreurs de compteur virtuel – Figure 1](/img/stoerungsbehebung-virtueller-zaehler-fehler/01.png)

Voici comment un compteur hors ligne apparaît dans la structure des dossiers.

Si c'est le cas, consultez la page suivante :

[Compteur hors ligne](/stoerungsbehebung/zaehler-offline)

Si vous n'avez plus besoin du compteur hors ligne, vous devez le supprimer, puis créer à nouveau le compteur virtuel.

Le problème devrait alors être résolu.

![Erreurs de compteur virtuel – Figure 2](/img/stoerungsbehebung-virtueller-zaehler-fehler/02.png)
