La nostra stazione di ricarica Pico dispone di uno schermo da 32 × 32 pixel su cui è possibile visualizzare animazioni GIF.
Nel portale web smart-me trovi già alcune GIF preimpostate, ma puoi anche caricare file propri per personalizzare ulteriormente la tua stazione di ricarica.

Il tutto funziona molto semplicemente con il sito web Piskel.

Che cos'è [Piskelapp.com](http://piskelapp.com)?
Piskel è un programma di disegno gratuito e basato sul web con cui si possono creare facilmente pixel art e GIF animate. Funziona direttamente nel browser, senza installazione, e offre un'anteprima in tempo reale in cui le animazioni possono essere riprodotte immediatamente. Oltre ai numerosi strumenti di disegno come pennello, strumento di riempimento, forme o modalità di simmetria, è possibile creare immagini pixel personalizzate fotogramma per fotogramma. Le animazioni completate possono essere esportate come GIF, spritesheet o singoli file PNG.

![piskelapp – Figura 1](/img/drittsysteme-piskelapp/01.png)

### Istruzioni per creare una GIF personalizzata

- Apri [piskelapp.com](https://www.piskelapp.com/) e clicca in alto a destra su "Create Sprite".

- A destra trovi le impostazioni – imposta la dimensione su 32 × 32 pixel.


![piskelapp – Figura 2](/img/drittsysteme-piskelapp/02.png)

- Seleziona a sinistra lo strumento di disegno desiderato e un colore.

- Disegna il motivo desiderato nell'area di lavoro.
    (Se desideri solo un motivo statico, puoi esportarlo ora come PNG.)

- Per un'animazione aggiungi un nuovo fotogramma e disegna il movimento desiderato.

- Esporta la tua creazione come GIF.
    (Importante: lo sfondo deve essere nero, la trasparenza non è consentita.)

- Carica il file GIF nel portale web smart-me.


![piskelapp – Figura 3](/img/drittsysteme-piskelapp/03.png)

### Istruzioni per convertire una GIF

Carica una GIF tramite "Importa" (Importieren) e adattala a 32 × 32 pixel. Successivamente puoi esportarla di nuovo come GIF e caricarla sulla tua stazione di ricarica Pico nel portale web smart-me.
