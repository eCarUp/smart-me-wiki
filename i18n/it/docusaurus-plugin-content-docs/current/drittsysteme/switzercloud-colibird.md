Switzercloud consente di collegare e raccogliere dati provenienti da diversi produttori, tecnologie di trasmissione, applicazioni e sistemi.

Con Switzercloud si raccolgono dati da dispositivi IoT con le più diverse vie di trasmissione, dai sensori LORAWAN ai dispositivi Ethernet fino ai trasferimenti diretti di dati da cloud a cloud (API).



1.  Raccogliere i dati

2.  Visualizzare i dati

3.  Elaborare i dati

4.  Allarmare e controllare


![Switzercloud / Colibird – Figura 1](/img/drittsysteme-switzercloud-colibird/01.png)

Switzercloud può richiamare, raccogliere ed elaborare i dati di misura dal portale smart-me tramite API.
L'elaborazione sfocia in allarmi, report, conteggi, comandi e/o visualizzazioni con l'aiuto di Colibird.
