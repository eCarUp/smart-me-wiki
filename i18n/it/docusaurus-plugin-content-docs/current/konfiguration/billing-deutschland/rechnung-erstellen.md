<div className="row">
<div className="col col--5">

Quando il riquadro blu delle tariffe virtuali si trova sulla data odierna, è possibile creare una fattura di prova.

- Inserire la data

- Creare l'anteprima della fattura (Rechnungsvorschau)

Se è soddisfatto dell'anteprima, può tornare indietro e creare le fatture effettive.

Congratulazioni, ce l'ha fatta! Quando genera fatture nello smart-me Billing Tool, ottiene un documento di fattura con tutte le indicazioni necessarie e le rappresentazioni grafiche.

In questa pagina trova una descrizione dei messaggi di errore più frequenti e delle possibili soluzioni: [Messaggi di errore Billing](/stoerungsbehebung/billing-fehlermeldungen)
