Quando il riquadro blu nelle tariffe virtuali (Virtuelle Tarife) si trova sulla data odierna, è possibile creare una fattura di prova.

- Menu Fatturazione (Rechnungsstellung)

- Fatture (Rechnungen)

- Inserire la data

- Creare l'anteprima della fattura (Rechnungsvorschau erstellen)

Se l'anteprima è soddisfacente, è possibile tornare indietro e creare le fatture effettive.

In questa pagina si trova una descrizione dei messaggi di errore più frequenti e delle possibili soluzioni: [Messaggi di errore del Billing](/stoerungsbehebung/billing-fehlermeldungen)
