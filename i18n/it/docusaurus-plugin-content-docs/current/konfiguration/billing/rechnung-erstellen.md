<div className="row">
<div className="col col--5">

Quando il riquadro blu nelle tariffe virtuali (Virtuelle Tarife) si trova sulla data odierna, è possibile creare una fattura di prova.

- Inserire la data

- Creare l'anteprima della fattura (Rechnungsvorschau erstellen)

Se l'anteprima La soddisfa, può tornare indietro e creare le fatture effettive.

In questa pagina trova una descrizione dei messaggi di errore più frequenti e le possibili soluzioni: [Messaggi di errore di Billing](/stoerungsbehebung/billing-fehlermeldungen)
