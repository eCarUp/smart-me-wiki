## Istruzioni per l''integrazione

## Collegamento del gateway al cloud smart-me

1.  Alimenta il dispositivo

2.  Collega il tuo laptop al Wifi del WIsGate Edge (RAK7268\_XXXX), non è necessaria alcuna password.

3.  Apri il tuo browser web e visita 192.168.230.1

4.  Accedi.
    Username: root
    Password: root

5.  Vai su Overview per leggere l'EUI, necessario per il successivo collegamento al cloud.

6.  Visita le impostazioni (Einstellungen) --> configurazione (Konfiguration)

7.  Effettua le seguenti impostazioni e salvale.

8.  Registra il dispositivo con il suo EUI nel LoRa Gateway smart-me
