Lo smart-me Meter è il primo contatore elettrico che può essere analizzato e comandato da qualsiasi luogo. Non è necessario alcun hardware aggiuntivo. Utilizza la rete WiFi esistente e si collega direttamente alla smart-me Cloud. In questo modo è possibile visualizzare comodamente il proprio consumo energetico in tempo reale.

Vendita cessata il 01.01.2023, il supporto e l'assistenza cloud restano garantiti.

![Contatore monofase 32A – Figura 1](/img/produkte-1-phasen-zaehler-32a/01.jpg)

## Funzioni

- Contatore di energia monofase, 230 VAC 50/60 Hz

- Misura diretta fino a 32 A

- Contatore bidirezionale

- Interfaccia a impulsi S0 aggiuntiva

- Classe di precisione 1 secondo IEC62053-21

- Datalogger integrato per due mesi (in caso di interruzione della connessione)

- Connessione diretta e crittografata alla smart-me Cloud (WiFi)

- Gestione energetica completa nella smart-me Cloud: 

    - Monitoraggio in tempo reale

    - fatturazione automatica ([smart-me Billing](/konfiguration/billing))

    - Comando con [azioni basate su eventi](/konfiguration/wenndann-aktionen/ereignisaktionen) e [azioni se/allora](/konfiguration/wenndann-aktionen)

- Installazione semplice con l'app smart-me gratuita per [Android](https://play.google.com/store/apps/details?id=com.smart_me) e [iOS](https://apps.apple.com/ch/app/smart-me/id929146952?ign-mpt=uo%3D4)

## Dati tecnici

| Caratteristica | Valore |
| --- | --- |
| Precisione | 1 secondo IEC62053-21 |
| Tensione di esercizio | 85 - 253 VAC |
| Frequenza (f) | 50 / 60 Hz |
| Corrente max. | 32 A (commutabile) |
| Ingresso a impulsi E1 | A potenziale zero\*, 25V - 253V AC/DC |
| Uscita digitale / uscita a impulsi S0 | A potenziale zero\*, Opto Power MOSFET, 5-48VDC / 5- 230 VAC, max. 550mW |
| Corrente di riferimento | 5 A |
| Corrente di avviamento | &lt; 20 mA |
| Tariffe | 2+ |
| Montaggio | Guida DIN |
| Larghezza | 2 moduli, 36 x 90 mm |
| Interfacce | WiFi, S0 |
| Valore impulsi S0 | 1000 impulsi per kWh |
| Autoconsumo | &lt; 0.5 W |

\*non dispone di una propria alimentazione di tensione.

## Configurare ingressi e uscite

Lo smart-me Meter dispone di un'uscita e di un ingresso, che possono essere utilizzati come ingressi e uscite a impulsi oppure come contatto commutabile a potenziale zero. I dettagli sono disponibili [qui](/schnittstellen/ein-und-ausgaenge).
