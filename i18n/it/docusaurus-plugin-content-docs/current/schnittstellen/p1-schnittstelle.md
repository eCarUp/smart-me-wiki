## Interfaccia P1

L'interfaccia P1 consente di trasferire i dati in tempo reale dal nostro hardware di misura verso sistemi di terzi. I dati possono poi essere utilizzati per l'analisi o per il comando.

Per poter utilizzare questa interfaccia è necessario un modulo di lettura P1 che supporti lo standard di protocollo.
Le informazioni sul relativo standard si trovano nei download specifici per prodotto.
