Lo stato del sistema (Systemgesundheit) richiede una licenza Professional 

Visualizzazione:

I dispositivi sono ordinati per tipo.

- Dispositivi Meter (Meter Geräte): contatori smart-me

- Dispositivi Pico (Pico Geräte): stazioni di ricarica Pico

- Gateway M-Bus (M-Bus Gateways): tutti i gateway

- Dispositivi M-Bus (M-Bus Geräte):
    Tutti i contatori generati dal gateway M-Bus.

- Altri dispositivi (Andere Geräte): dispositivi API o importati


Ordinamento:

Le colonne possono essere ordinate, ma per impostazione predefinita sono disposte in modo che tutti i dispositivi offline compaiano in cima.

ID dispositivo (Device ID):

È l'ID con cui questo contatore può essere indirizzato direttamente tramite API.
