Lo stato di salute del sistema (Systemgesundheit) richiede una licenza Professional 

Visualizzazione:

I dispositivi sono ordinati per tipo.

- Dispositivi Meter: contatori smart-me

- Dispositivi Pico: stazioni di ricarica Pico

- M-Bus Gateways: tutti i gateway

- Dispositivi M-Bus:
    tutti i contatori generati dal gateway M-Bus.

- Altri dispositivi: dispositivi API o importati


Ordinamento:

Le colonne possono essere ordinate, ma sono disposte in modo predefinito affinché tutti i dispositivi offline compaiano in cima.

Device ID:

È l'ID con il quale questo contatore può essere interrogato direttamente via API.
